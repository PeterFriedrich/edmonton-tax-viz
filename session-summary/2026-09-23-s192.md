## 3. Technical Learnings
- ⚠️ **A zero z-scale in deck.gl's `modelMatrix` darkens lit prisms by about 38%.** Normals go through the same matrix, and roofs lose their lighting. With `1e-4`, the sampled pixels are identical to tilted roofs.
- **Re-cloning built layers with a new `modelMatrix` is cheap** because it's a uniform. Per-frame animation must re-clone a list built once (`base`). Never call `buildLayers()` per frame: `topRings` is about 89k vertices.
- **MapLibre's `easeTo` front-loads its motion.** On the 52° → 0° ease, pitch is already **2.0°** at t = 0.75. Time-based "last quarter" effects look like an end-snap.
- **`easeTo` calls `stop()`, which fires `moveend`.** Register `moveend` listeners AFTER calling `easeTo`, or they disarm immediately.
- **Headless swiftshader runs at about 6 fps with multi-second stalls.** Per-frame checks must be frame-rate independent: check that samples sit on a curve, and use a slowed 8 s ease to catch a partial frame. CSS transitions (0.12 s) also stretch past 400 ms, so poll for the computed style.
- ⚠️ **`verify-temporal.js` is flaky ON MASTER.** It failed 2 of 4 runs with `money / non-residential: control #revcut ... is clickable — Timeout 4000ms`. It isn't caused by this session's changes, and it isn't fixed.
- **The findings doc's "costs nothing today" claim for F6 had been measured on only one search.** The control run caught it, because the new check failed with no mutation applied. Always run an unmutated control.
- **Script-top-level `let`/`function` bindings (`camFlat`, `squashZ`, `flattenDuringEase`, `overlay`) can be read and reassigned from `page.evaluate`.** The wiring spy relies on this.
- **Editing `web/index.html` with Python or sed doesn't fire the CODEMAP hook.** Run `.venv/bin/python tools/codemap.py` by hand.
- **The S191 mutation harness still exists** at `/tmp/claude-1000/-home-opc-edmonton-tax-viz/5736c4b7-.../scratchpad/mutate.py`. A copy with controls and F5–F8 scenarios is in this session's scratchpad. Neither is committed, and both are ephemeral.
