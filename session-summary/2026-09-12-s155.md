## 3. Technical Learnings

### 3a. What the public build now ships

Public `#views` is **4 buttons**: Money · Development · Services · Ratio. Uses is
the **last lens still full-only**. Services ships roads-only via `SERVICES[k].pub`
(3 of 11 rows). Ratio ships **roads-only via a different mechanism** — see 3b.

### 3b. ⚠️ Ratio's public gate is the PICKER'S ABSENCE, not a tag

The fire-event denominator is full-only, but it needed no `pub` tag: fire is
already a full-only service, so `ratioDenomShow` just gained `&& FULL_BUILD` and
the public build renders no `#ratio-denom` control at all. **That absence is the
entire gate**, and it holds *only* because nothing persists or URL-restores
`state.ratioDenom` (verified: the only `URLSearchParams` use in the file is the
`build` override). With no control, its `roads` default cannot be moved off.
⚠️ **If any state-persistence or permalink feature is ever added, this gate
breaks silently** — that is the thing to re-check.

### 3c. ⚠️ THE BIG ONE — Money's consequence tier does NOT port to a log ramp

Ratio's exempt hoods were drawn as ordinary solid prisms with point values while
Money drew the same hoods as azure ranges. Fixing it exposed a real trap:

Money's second tier asks *do the two worlds draw different prisms?* via
`instShiftMoney`. On Ratio's **log** ramp that shift is
`ln(v) − ln(v(1−e)) = −ln(1−e)`, over `logSpan` — **algebraically independent of
the hood's own value**. It is not a second question at all, just a share test
wearing a consequence costume (`e ≥ 0.469` at today's anchors).

⚠️ **And at the clamps it selects BACKWARDS**, dropping exactly what it exists to
catch. Measured on the 2026-09-12 data:

| hood | exempt | shift | naive port |
|---|---:|---:|---|
| UNIVERSITY OF ALBERTA | 90% | **0.229** | dropped — log compresses its 9.9× span *by design* |
| RIVER VALLEY GOLD BAR | 90% | **0.000** | dropped — both endpoints clamp below the p2.5 anchor |

A naive port bands **6** hoods and excludes both 90% cases. So `instBandedRatio`
uses **`EXEMPT_UNCERTAIN_MIN` (share) alone → 16 hoods**. ⚠️ **Do not "restore
parity" by adding a consequence term** — `verify-ratio-denom.js` check 10 pins
both 90% hoods by name and reddens 8 checks if you do.

### 3d. The band is shaped on GLASS, not Money

Ratio is a **ghost-prism** view, so `ratioInstBandLayers()` follows
`glassInstBandLayers`: the azure rides `state.prismOpacity` (Glass's measured
reason — at a fixed 1.0 it stops reading as part of the composition) and is
**`pickable: false`**, because `hoodHoverLayer` already covers every footprint.
⚠️ **Money's `pickable` + `bandHover` machinery must NOT be ported** — it solves a
fall-through-to-the-hood-behind hazard that Ratio does not have.

### 3e. ⚠️ A residue's expiry LICENSES a change; it does not AUTHORISE it

The Money tooltip's `$ revenue / road metre` row was pulled 2026-07-28 for one
stated reason — its explaining lens was hidden. When Ratio returned, that reason
genuinely expired, so I un-gated it inside the lens's own PR. **Peter reversed it
within the hour** (*"Yeah I don't want the extra tooltip on money"*). The gate now
rests on a **different footing** — how much the default view's tooltip should
carry — and the code comment at the use site says so, so the next lens move does
not re-derive it open. Generalised in `CONTROLS_MATRIX.md`: **propose a residue's
return, don't ship it inside the lens's own change.**

### 3f. ⚠️ Environment quirks that cost real time

- **`python3 -m http.server` WEDGES after each Playwright run on this box** —
  it stays alive and listening but returns empty responses (`curl` → `000`,
  Playwright → `ERR_EMPTY_RESPONSE`). It looks exactly like a crashed page.
  **Kill and restart the server before every verify run**, and confirm with
  `curl -sf -o /dev/null -w '%{http_code}'` first. Get its pid from
  `ss -ltnp | grep <port>`, not `pgrep -f` (which matches the shell that ran it).
- **Probe scripts must live in the repo**, not the scratchpad — `playwright` only
  resolves from `/home/opc/edmonton-tax-viz`. Write to
  `tools/profiling/_probe-*.js` and delete after.
- **`overlay.props.layers` is undefined**; use `buildLayers()` in page evaluates.
