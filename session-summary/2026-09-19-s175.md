## 3. Technical Learnings

- ⚠️ **The formatter family had ZERO test coverage and still does.** All 7,904
  lines of `web/index.html` are verified only by Playwright `verify-*.js`. Pure
  string-in/string-out functions are the easiest thing in the repo to test and
  the least tested. **Peter chose to extend `verify-*.js` rather than add a JS
  unit-test runner** — `STACK.md` §9 forbids a JS toolchain in the publish path,
  and the S3 precedent (run the SHIPPED formatter over served rows) cannot pass
  against a formatter the page does not use, which a fixture-based test can.
- ⚠️ **Only `verify-smoke.js` runs in CI.** Verified by grep over
  `.github/workflows/`. Before putting a guard in a `verify-*.js`, decide
  whether it needs a reader — if it does, it goes in smoke, and it must then be
  **invariant-only**, never a pinned data value.
- **A guard can out-measure the analyst who wrote it.** My python sweep said 16;
  C9 said 21, because it derives its columns from `METRICS` plus an explicit
  list and I had hand-listed a shorter set. **Prefer deriving the target set
  from the page's own config over enumerating it by hand.**
- **`git cherry master <branch>` is the right tool for "is this branch's work
  actually on master?"** — `--merged` misses content that landed under a
  different SHA (rebase, re-commit, or a **file move**, which is what made
  `docs/premise-tests` look unmerged).
- **System `python3` on this box is 3.6 and has no `http.server --directory`.**
  Use `.venv/bin/python`. Confirm the serving root by **content**
  (`/verified/` → 200, `/src/` → 404), not by `/proc/<pid>/cwd`, which misled
  here (`confirm-the-server-you-measure`, live instance).
- **`git add -A` is dangerous in this repo after a local build.** `_site/` is
  now ignored; the general lesson is to read `git show --stat` before pushing.
- Important locations:
  - `web/index.html` — `money0` sits immediately above `fmtMoney`; the seven
    dollar formatters and `fmtMix` all reference it
  - `tools/profiling/verify-smoke.js` §C9 — the invariant, CI-run
  - `tools/profiling/verify-services-panel.js` §3c (percent) and **§3d** (dollar
    non-vacuity) — hand-run
