## 3. Technical Learnings
- **Transcript parsing:**
  - One API response is split across several JSONL records that repeat
    `usage`. Dedupe by `message.id`, or tokens inflate ~1.8×.
  - A main-session transcript has no compaction markers.
  - `output_tokens_details.thinking_tokens` is populated.
- **Model time fits 12.2 ms per output token, ~0 s per call (R² 0.95).** Session
  speed is output-bound, so cutting output is the only generation lever.
- **Chars per token on this repo is ~2.4** for both markdown and code (168
  single-tool turns). Byte-based token figures in the docs are ~1.7× low.
- **Classifying Bash by file names is wrong.** Classify each shell segment by
  its program:
  - lift heredocs first;
  - mask quoted strings before splitting on `|`, or a `grep "a\|b" FILE` loses
    its path.

  A 20-per-bucket spot check caught both bugs.
- **The base context grew 23k → 50k tokens** (08-28 → 10-10). The project's
  `CLAUDE.md` accounts for only +2.5k of that; the skill listing and
  deferred-tool lists grew most (harness/account side).
- **`check_doc_citations.py` reads quoted text after a doc name as a citation.**
  So `` `X.md` "old wording" `` in a findings table adds a warning, and so does
  naming `MEMORY.md`. Keep the quoted-title warnings at 9.
