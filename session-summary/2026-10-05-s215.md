## 3. Technical Learnings
- **A Socrata 0-row table serves a header-only CSV** or `features: []`.
  `download_data.py`'s check (local == `count(*)`) passes 0 = 0.
- **ETS zip:** `https://gtfs.edmonton.ca/TMGTFSRealTimeWebService/GTFS/GTFS.zip`
  returns 403 without a browser User-Agent.
- **GitHub Actions:**
  - `actions/checkout` defaults to the event SHA.
  - A concurrency group's default `queue: single` cancels the pending run.
    `queue: max` exists and is compatible with `cancel-in-progress: false`.
- **Mutating a built page:** edit both `index.html` and
  `dev-build-full/index.html` in a `build_site.py` output, then run
  `verify-smoke.js` with `NODE_OPTIONS=--require=./fast-teardown.js`.
- `openTemporal(name)` and `state.svcDriver` are reachable via
  `page.evaluate`.
- **Colour sampling:** use pitch 0. At pitch 50 the centre pixel can be a
  neighbouring prism.
- `.venv` has Pillow and pypdf, but no `skimage`, `colour` or `pdftotext`.
- The retrieval log has logged Bash reads since 09-21: 1,588 entries.
- The report session had already archived `s212`. **Check what is top-level
  before archiving.**
