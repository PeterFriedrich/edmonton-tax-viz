## 3. Technical Learnings

- ⚠️ **The 2025 ISC's Appendix B (p37) prints the Roads row's SUB-ROWS**, which
  is what broke §4b. Any claim built on a multi-edition "Roads" aggregate must
  decompose it first: the composition changed in **every** edition (alleys in
  2020; a $2.1B Curbs line appearing in 2025; Paved Roads *shrinking* $9.7B →
  $8.2B while the total grew, which is how we know curbs were inside the 2023
  paved line).
- ⚠️ **`grep -c` counts LINES, not occurrences.** Cost me a wrong count that an
  assert caught. Use `grep -o | wc -l` or python.
- ⚠️ **A copy change is a GUARD change.** Nine verify scripts asserted on
  reader-facing strings; the one-pass rule in `COPY_DECISIONS.md` is enforced by
  those guards, not by care. **Grep every verify script for the literal before
  editing copy** — and grep again after, because `verify-revenue-panel.js` had a
  fourth occurrence outside the block the first grep showed.
- ⚠️ **No guard catches a panel that reads badly.** S2's duplication passed every
  check. **Render the panel and read it** (`tools/profiling/_panelshot.js` was
  written for this and DELETED afterwards — it was scratch, not an artifact).
- ⚠️ **Playwright resolves only from `tools/profiling/node_modules`** — a script
  in the scratchpad cannot `require('playwright')`. Node resolves from the
  SCRIPT's directory, not cwd.
- **`verify-peek.js` went red once under sequential load and green alone**, as
  `run-verify-scripts-alone` predicts. The red was in an unrelated check
  ("desktop: ONE click still pins"), which is the tell.
- **Server hygiene held**: started from `web/` with an absolute interpreter path,
  confirmed via `/proc/<pid>/cwd` **and** by grepping the served bytes for the
  new title before trusting any run.
- **All City fetches need `certifi`**; `www.edmonton.ca` soft-404s with HTTP 200
  (check the title). `budget.edmonton.ca/api/capital_budget.csv` is live and the
  FY2023–26 Neighbourhood Renewal Reserve draw reproduces the repo's recorded
  **$719,953,000** exactly.
