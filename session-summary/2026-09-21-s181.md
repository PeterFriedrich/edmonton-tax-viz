## 3. Technical Learnings

- ⚠️ **AN AUDIT BRIEF'S PREMISES ARE CLAIMS, NOT CONTEXT — THREE OF THIS ONE'S
  WERE WRONG.** The rate, the lens's denominator and the build the temporal
  lens ships on were all stated as settled fact in the request. Each was
  checkable in under a minute and each was wrong. **Had they been accepted as
  framing, the report would have confirmed them back.** Same family as
  `todo-can-lag-executed-work`, one level up: **a brief can lag reality exactly
  like a backlog item, and a brief written by someone who cannot see the repo
  lags hardest.**
- ⚠️ **A DOC ON THE LOADED PATH DRIFTED FROM THE CODE AND NOTHING CAUGHT IT.**
  `CLAUDE.md` says the temporal lens is `/full/`-only; the fetch has been
  unconditional and the public root serves `temporal.json` with a 200. The
  *code comment* at `:6202` carries the same stale belief. **`CLAUDE.md` is
  read by every session, so this is the highest-leverage kind of staleness** —
  and `check_doc_citations.py` checks that cited files EXIST, not that claims
  about behaviour are TRUE.
- ⚠️ **"IS IT PINNED IN CI" HAS TWO ANSWERS AND ONLY ONE MATTERS FOR A MERGE.**
  The value anchors run in `refresh.yml` (weekly), **not** `tests.yml` (merge
  gate). "There's a guard" was true and would have been misleading. **Name the
  workflow, not the guard.**
- ⚠️ **A DESCRIPTIVE AUDIT SCRIPT EXITS 0 WHETHER OR NOT ANYTHING IS WRONG.**
  `audit_cardinality_denominators.py` prints; it does not assert. **Reporting
  it as "PASS" would have manufactured a verdict the tool never issues.**
- **THE TOOL FOR THE AUDIENCE ALREADY EXISTED AND WAS NOT IN THE BRIEF.**
  `tools/ward_rollup.py` answers the councillor's actual question (revenue vs
  road renewal, per ward) and nothing pointed at it — it is not on the site and
  no doc in the loaded path names it. **Searching `tools/` for the audience's
  unit of analysis was worth more than any answer inside the five sections.**
- **VERIFY A RATE AGAINST THE SERVED DATA, NOT ONLY THE JSON THAT DECLARES
  IT.** Dividing Delton's `cost_roads_ops_per_acre` by its `road_m_per_acre`
  returns $9.32 — proof the pipeline **consumed** the re-scoped rate, which the
  JSON alone cannot show. Same check caught nothing wrong, but it is the check
  that *could* have.
