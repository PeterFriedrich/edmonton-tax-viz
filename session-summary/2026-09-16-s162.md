## 3. Technical Learnings

- **The guard's first cut failed on its own marks** (`PARTLY AMENDED 2026-08-15`
  read as an announcement of a 2026-08-15 supersession with no such earlier row —
  9 false fails on the 9 rows it had just asked for). `IS_MARK` skips them and
  `test_the_mark_is_not_itself_an_announcement` pins it. Same family as
  `check-where-the-value-can-be-wrong`: the instrument was wrong in the direction
  that created work.
- **Verb-near-date is not an announcement.** 22 hits → 4 were "had already been
  retracted on 2026-08-11", a quoted date next to "reversed", "Peter reversed".
  The pattern now requires the target to be named as a ROW (verb → ≤8 tokens →
  `the <date>` / `same-day` / `row above`) and skips `<verb> on <date>`.
- **System `grep` is ugrep and rejects `-o -E` patterns with `.{0,80}` around
  alternations ("exceeds complexity limits").** Use python for context windows.
- **`tools/todo_archive.py` takes no `--help` — any invocation runs it.** Harmless
  here (it verifies no line is lost) but check the diff.
- `check_doc_citations.py`'s `any_md` warning flags any `UPPER.md` token even in a
  code string — write `("MEMORY" ".md")` or say "the memory index" in prose.
- Line numbers in `DECISIONS.md` shift when the header grows; the second batch of
  marks matched on row title prefixes instead.

## 6a. The `$50k` clamp — DECIDED and GUARDED (PR #421)

**Decision: it stays a stability literal.** The finding that settled it was not in
the audit: **the same file already computes the percentile in two other places.**
`moneyScale`'s lot-acre branch and `gridScale` both use a live
`quantile(vals, 0.975)` and render the legend from it (`cfg.fmt(sc.clamp) + "+"`),
with a comment saying the self-anchoring is so it "tracks weekly refreshes". So
stability-vs-percentile was never an open question project-wide — it is settled
**both ways, deliberately**, and the ground-acre landing view is the only scale
still on a literal, because it is the one that must be comparable between visits.

⚠️ **This was surfaced to Peter as an argument AGAINST the choice he had just
made**, since it arrived after his decision. He kept the literal.

**The falsification is the headline, and it reproduces the audit exactly:**

```
colorClamp: 50_000 -> 5_000, legend left reading "$50k+"
  => all 923 pre-existing tests PASS. Only the 3 new ones go red.
```

`verify-res-revenue.js` / `verify-smoke.js` pin `$30k+` and `$4M+` as strings and
**do not pin `$50k+` at all** — the audit's "presence guard" finding was, if
anything, understated.

`scripts/check_colour_clamps.py` splits two failures that need different answers:
- **legend string must decode to `colorClamp`** — FAILS, merge gate (`tests.yml`)
- **saturating share outside 1–6% of live hoods** — WARNS each refresh, files a
  `clamp-drift` issue, **never blocks** (`refresh.yml`)

⚠️ **The band CONTAINS today's 4.5% on purpose, and that is not vacuity** — 4.5%
is the share Peter accepted by keeping the literal; a band excluding it would red
the gate to force a decision already made. It catches the *next* move, and is
falsified in BOTH directions in the tests so it cannot be a green-only guard.

Measured 2026-09-16 (358 non-set-aside hoods; re-derived, matches the audit):

## 7c. The handoff hooks now measure instead of nag (#427)

never under-supplied: **six places** carried the rule, and both hooks echoed one
fixed sentence whether eight PRs had landed or none. A warning that always fires

**Rejected: folding it into a skill.** A skill fires on invocation; this must fire
