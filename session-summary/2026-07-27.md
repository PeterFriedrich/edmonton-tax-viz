**DATA FINDINGS (all verified against live services, 2026-07-26/27):**
- **`gis.edmonton.ca` IS reachable from this box even though `edmonton.ca` is
  NOT.** Different host. `data.edmonton.ca` also fine. (Did not end up needing
  it — the ravine layer was cut.)
- Both Alberta services are natively **EPSG:3400**, the pipeline's working CRS.
- **The brief's `web/data` CRS instruction was wrong and was NOT followed.**
  Everything in `web/data/` is **4326** (deck.gl/MapLibre need lon/lat); 3400 is
  the *working* CRS for the geometry ops so simplify tolerances are honest
  metres. Both are right in their place — the script does 3400 → 4326 on write.
- **Strathcona County is sublayer 104 (`Specialized Municipality`, `SPMUN_NAME`),
  NOT 114 (`Municipal District and County`)** — the brief conflated them. 114
  holds Leduc/Sturgeon/Parkland *County*. Edmonton / St. Albert / Leduc are all
  in **78** (`City`, `CITY_NAME`). Ids 67/95/105 are **group layers** and return
  no fields. **Recorded in TODO.md for the Tier 3 PR.**
- River: `base_water_feature` **layer 72** (`Lake/River (20K)`).
  `NAME='North Saskatchewan River'` isolates cleanly — 7 polygons province-wide,
  all genuinely the river.
- **At the 60 km clip the river is a `MultiPolygon`** (disjoint stretches up-
  and downstream); at 3 km it was a single `Polygon`. My own verify had pinned
  the narrow case and **failed on the rerun** — now accepts either.

**THE RING ROAD WAS THE HARD PART (all in `build_reference_layers.py`):**
1. **Name-matching alone gives 275.7 km across 590 segments, not the ~75 km
   ring** — every entrance/exit ramp, right-turn cutoff and
   collector-distributor lane is *named* for the highway it serves. Fixed with
   an explicit `road_segment_type_description` allowlist
   (`HENDAY_MAINLINE_TYPES`) → 149 km. **The two `Structure -` types are IN,
   not out** — they carry the mainline over the river and cross streets;
   dropping them gaps the ring at every crossing.
2. **A 2.9 km hole remained in the east leg = 73 screen pixels**, which reads as
   a rendering bug. **Highway 216 runs CONCURRENT with Highway 14** there and
   the feed labels the shared carriageway for Highway 14 only. Confirmed by
   probing the hole: every sample point sits **1–35 m** from a Hwy 14
   centreline. Only `HIGHWAY 14 NORTHBOUND`/`SOUTHBOUND` are the concurrency —
   `EAST`/`WESTBOUND` is Hwy 14 leaving the ring (a 5 km spur if included).
3. Pulling the concurrency in **overshoots** by ~1.7 km + ~1.3 km past the
   junction. Pruned **by topology** (`_prune_spurs`: a ring has no loose ends),
   iterated, **not** by a coordinate cutoff or length threshold.
4. **THE CHECK IS THE POINT:** 149 km looks perfectly plausible for a 75 km ring
   drawn twice, so **no length total would ever have caught the hole**. Only
   "does every arc end meet another arc end" (`_dangling_flags`) did. Note the
   first version of this check tested *per-part closure*, which was right for 2
   arcs and **wrong once the concurrency legitimately fragmented the ring into
   8** — dangling-endpoint counting is the formulation that survives.
5. Both carriageways are kept (~156 km, 28 m apart, coincident at 1 px).

**⚠️ PRE-EXISTING FLAKY TEST FOUND (logged in TODO.md, deliberately NOT fixed
here):** `verify-uses-prisms.js` → *"money: control hidden again, state kept"*.

8931"` returns **exit 144** and aborts a compound command — run it alone.

playwright scratch scripts go INTO `tools/profiling/`, named `_*-tmp.js`, and
get deleted (three created and removed this session, plus their `_*.png`).
(d) `page.screenshot` needs an explicit `timeout: 60000`. (e) **Commit messages
containing double quotes break `git commit -m`** — write to a file and use
`git commit -F` (used three times this session). Same for apostrophes in `sed`
replacement text. (f) Docs-only pushes go straight to `master`; anything
touching `web/**` needs a branch + PR. (g) `edmonton.ca` unreachable;
**`data.edmonton.ca` AND `gis.edmonton.ca` are both fine.** (h) Running several
verify scripts in one `for` loop **exceeds the 2-minute Bash timeout** — run
them individually or in pairs with an explicit `timeout`.
