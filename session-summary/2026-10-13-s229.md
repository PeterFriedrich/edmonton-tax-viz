## 3. Technical Learnings
- **A map `render` event after `addControl` is not a deck frame.** In
  interleaved mode deck 9.0.38 adds no MapLibre custom layers
  (`map.getStyle().layers` shows none) and `onAfterRender` also fires on a
  draw with zero layers, so the gate has to check the layer count.
- **Whether the overlay bug shows is a race.** Served from localhost the boot
  GeoJSON can land before the map's first `idle`; then the basemap gate is the
  late one and the overlay lifts with all 22 layers up. Delay the data file to
  test the data gate. `verify-loading-overlay.js` was red on master on its old
  idle check before any change; the commit that turned it red was not found.
- **deck "pixel" text is true only at the focal point.** On a tilted camera
  names at the front drew about 1.5× those at the back. Depth is
  `m[3]*x + m[7]*y + m[11]*z + m[15]` over `vp.projectPosition(...)` with
  `m = vp.viewProjectionMatrix`.
- **The label layer exists only while its pool is non-empty.** A verify check
  that reads `hood-labels` props must run at HOME with reference names up. The
  font check was first placed at a leftover camera and went red when the
  visible names changed.
- **deck caches its glyph atlas per font key.** Text drawn before a web font
  lands stays in the fallback for the visit; hence the await in `boot()`.
- **Neither deck.gl nor MapLibre ships a font**, and the page had no
  `@font-face` at all. deck's draw scale for Source Sans 3 is still 1.2625, so
  `LABEL_DRAW_SCALE = 1.35` stands.
- **This box cannot render weight variants in its own fonts** (Cantarell
  Regular/Bold and DejaVu Sans Mono only). Mockups need a font file injected
  with `page.route`; say which font a sheet was drawn in.
- **Alberta's county polygons run over reserve land.** Any anchor or area taken
  from a county polygon includes it.
- **Alberta's `boundaries/federal_indian_reserve` service is copyright Alberta
  Data Partnerships Ltd.**, not the Government of Alberta. The federal copy has
  the same three parts and area.
- **Overpass returned 504 four times** (once on the airport query, then three
  full builds in a row). The build has no retry.
- **A `;` after a failing verify let me commit and open #738 with "green" in the
  body.** Corrected in the PR. Chain verify runs with `&&` before a commit.
- **Mockup scripts live in the scratchpad** of session `eb93c5d1-…`:
  `overlay-probe*.js`, `label-variants.js`, `place-variants.js`,
  `font-check.js`, `enoch-shot.js`. They patch `index.html` through
  `page.route`, so nothing in the repo is touched. The scratchpad is not kept.
