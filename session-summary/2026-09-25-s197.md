## 3. Technical Learnings
- **Verified notebooks now run AFTER the status manifest.** A failure still stops the run before the commit, so the manifest goes unbumped and the staleness banner fires. `02_methods.py` is the only notebook that reads `status.json`.
- **pandas 3.0.3:** `~` on an object Series of True/False gives the integers −1 and −2. A partial left-merge leaves `eligible` as object dtype, so `.loc[~x]` raises `KeyError`. It can look like a check firing when it isn't one. Use `.fillna(False).astype(bool)`.
- **Upstream guards the notebook need not duplicate:**
  - `check_value_anchors.py` bounds `ineligible_value_frac` (refresh.yml ~l.138);
  - `check_served_columns.py` `empty_columns()` catches an all-null served column.
- **The public build ships only these services:** `roads`, `roadscost` and `roadslife` (`pub: true` in `SERVICES`). `ratioDenomShow` is `&& FULL_BUILD`.
- **`load_assessment` drops 53 null/zero-value roll rows** (439,622 → 439,569). They are logged at INFO, which the notebook's WARNING level hides.
