## 3. Technical Learnings
- **The register's tags are one model's reading**, backfilled from ledger summaries. Several of the tagged audits were run by the same model family. Treat the class boundaries as approximate until a different model re-tags a sample.

- **The four `verify-{glass,labels,services,uses}.js` scripts are one-off probes.** They `console.log` values without asserting anything. `verify.js` classifies by FAIL lines plus exit code, so they always show `ok`, with 0 checks.
