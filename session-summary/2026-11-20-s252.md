## 3. Technical Learnings
- **A click timeout with "visible, enabled and stable" in the call log can be rAF starvation, not movement.** Here it was SwiftShader holding frames with idle JS. A standalone probe of the same two clicks did NOT reproduce it (60 fps). It only stalled with the script's earlier state built up, so instrument inside the real script.
- Playwright's error `message` here is one line. Run with `DEBUG=pw:api` to get the call log (it goes to stderr, with ANSI codes).
- A CPU profile from a test script: `page.context().newCDPSession(page)`, `Profiler.enable` / `setSamplingInterval` / `start` / `stop`. Sum `timeDeltas` per `callFrame` and subtract `(idle)` to separate JS-busy from compositor-blocked.
- **Bash gotcha:** `S=… && (cd $S/site && exec server) & SP=$!` backgrounds the whole and-list, so `S` is unset in the foreground. Set variables in their own statement. To serve a dir, use `python -m http.server --directory`.
- `verify-temporal.js` takes ~55 s per build; `verify-theme.js` ~500 s (covers both builds itself, needs the built tree).
- Before an exemption change in `verify-theme.js`, trace the colour's data source through git (`git show <sha>:web/data/...`), not just today's file. The dropped exemption was right for 52 minutes.
