## 3. Technical Learnings
- **Hover and selection on one deck.gl layer.** The picking module highlights one object per layer, so a held selection highlight and `autoHighlight` hover cannot share a layer. A 1-feature clone with `highlightedObjectIndex: 0` lights even with `pickable: false` (deck 9.0.38, verified by pixel diff).
- **YAML flow mappings split at commas.** In `- { flags: --views-except=a,b,c }`, the commas end the value. Quote any matrix value that contains a comma. The test now pins this.
- **Search framing in 3D can hide the picked hood.** `flyToHood` (maxZoom 12.5, current pitch) can leave the hood behind nearer towers. In the GARNEAU probe only one lit wall showed. Raised to Peter; he gave no answer.
- **GitHub job logs:** use `gh api repos/<o>/<r>/actions/jobs/<id>/logs`. `gh run view --log --job` returned other jobs' lines mixed in.
- **Merging before `url-state` finishes:** it is not a required check, so merging is allowed. The PR run continues and a red emails Peter, but the deploy has already happened.
