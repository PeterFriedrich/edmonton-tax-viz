## 4. Technical Learnings (don't re-derive)

- **This remote VM ships bare**: no geopandas (install
  `requirements-ci.txt`), no raw data, no conda. `pip install -r
  requirements-ci.txt` + pytest from repo root just works (209 green).
- **Headless verify on the VM needs two workarounds** (both scratchpad-
  only, nothing committed): (1) Playwright pins browser build 1228 but
  `/opt/pw-browsers` has 1194 — symlink `chromium_headless_shell-1228` →
  `-1194`, plus inside it `chrome-headless-shell-linux64` → `chrome-linux`
  and `chrome-linux/chrome-headless-shell` → `headless_shell`; (2) the
  page's unpkg CDN scripts are ALSO policy-blocked — `npm pack
  maplibre-gl@4.7.1 deck.gl@9.0.38` (registry.npmjs.org IS allowed),
  copy `dist/maplibre-gl.{js,css}` + `dist.min.js` into a `vendor/` dir in
  a COPY of web/, sed the three unpkg URLs to `./vendor/…`. Mock bed +
  server: copy web/ to the scratchpad, inject a synthetic
  `fire_events_per_acre` into the geojson copy + a fake 31-station
  `fire_stations.json`, `python3 -m http.server 8799` from the copy.
- **WebSearch/WebFetch are not a backdoor**: WebFetch obeys the same
  proxy (403), and the Socrata catalog API + dev.socrata.com +
  opendataedmonton.ca are all blocked. WebSearch (Anthropic-side) works
  but surfaced no field names for `7hsn-idqi`.
- **Averaging = total kept events ÷ len(years)** with implicit zero-fill
  (a hood missing a year contributes 0 for it) — equivalent to the mean
  of per-year counts, one groupby instead of a pivot.
- **pandas 3.0.3 quirks in this env**: `pd.to_datetime(...,
  format="mixed")` works; a `.replace(NAME_CORRECTIONS)` on a
  `string`-dtype Series behaves as exact-match replace (used for hoods,
  same as load_stormwater).
- **`#legend-cats` is reusable outside the Uses view** — refreshLegend
  sets it `display:none` for non-uses views first, so a later branch can
  re-show it (the fire station row does).
- **Peter's answer style this session**: asked how to proceed on the
  network block via AskUserQuestion — he answered with a question ("Why
  does this thing block it?") and then declined the re-ask; proceeded on
  the recommended synthetic path per the original "build it" instruction.
