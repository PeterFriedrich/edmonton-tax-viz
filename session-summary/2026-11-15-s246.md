## 3. Technical Learnings
- **`verify-blurbs.js` runs only on the public build.** On `web/` it reports "PARTIAL — ran 0 checks". Build first with `.venv/bin/python scripts/build_site.py --src web --out <scratch>/site`, then run `node tools/profiling/verify.js --serve <scratch>/site blurbs`.
  - `verify.js --page 'index.html?build=public'` does **not** work: it checks the path exists on disk.
  - To see which states break B5, run the script directly against a server. The runner hides its indented `bad` lines.
- **`verify-guide.js` fails on the full build** ("names in the card are the buttons on screen": Uses and Labbeta views show). Run it on the public build. This is pre-existing and not a regression.
- **Unfiltered `24uj-dj8v` coverage queries dilute the geocoding drop:** 62–77% for all types against 21–44% for new construction. Filter on `NEW_WORK_TYPES` when quoting it.
- Blurb character budget: Non-residential states were the tightest (up to 440 with the drafted clause). Total lot went to 402 with "Tax-exempt"; "Exempt" brings it under 400.
