## 3. Technical Learnings
- **Pages deploys ONLY via `refresh.yml`** (`build_type: workflow`; the
  `source.branch: master` in the Pages API is vestigial). Triggers = weekly cron
  (Mon 08:00 UTC) + `workflow_dispatch`. **A merge to master does NOT deploy** —
  dispatch the workflow (`gh workflow run refresh.yml`) or wait for Monday. The
  deploy job re-uploads the WHOLE `web/` dir every run, so app-code changes ship
  even when `web/data` didn't change (that's why a code-only change deploys but
  `status.json` `generated` can stay the prior date).
- **Confirm "is my change live" by the BLURB text, not the render** — cache
  serves stale `index.html`. `curl -s <pages>/index.html | grep <marker>` from the
  Oracle box works (github.io is not laptop-gated, unlike edmonton.ca).
- **Anchored-window idiom**: for a cumulative "since YEAR" window, DERIVE the end
  from the existing pinned tuple (`range(START, PERMIT_YEARS[-1]+1)`) instead of a
  new pin — auto-rolls with the January bump, inherits partial-year safety. The
  3yr window is a separate pin ONLY because its start slides; an anchored window's
  start doesn't, so deriving is safe + lower-maintenance.
- **A choropleth-only window/metric hides the detail grid** via a single
  `devGridOfferable() = !!devGridData && !devIndustrial() && !devLongWindow()`
  gate, reused in `applyView` + `applyDevMetric` + `applyDevWindow` (new
  `syncDevChrome()` helper). `devGridActive()` (render) adds `state.devGrid`.
- **median-year-built can't separate equally-new areas** — it's a stock SNAPSHOT;
  new suburbs are all ~2015 so uniformly tall by construction. For intra-new-build
  differentiation you need a FLOW/rate metric (units added, density, growth),
  which is what "New homes" + the long window give.
- **`gh run watch <id> --exit-status` buffers output** — it prints nothing until
  the run finishes, so it looks hung; poll `gh run view <id> --json status,jobs`
  for interim state instead.
- **playwright resolves only from `tools/profiling/`** (node_modules there) — a
  screenshot script copied to `/tmp` fails `require('playwright')`; run it from
  repo root with a `tools/profiling/` path (learning re-confirmed this session).
- **check-PR-state, AGAIN** — Peter merges mid-session AND leaves you on the
  merged branch. Before committing new work: `git fetch`, verify the old branch
  merged, and `git checkout -b <new> origin/master` (uncommitted changes carry
  over cleanly if non-conflicting).
