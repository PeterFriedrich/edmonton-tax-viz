## 3. Technical Learnings

- ⚠️ **THE ONE TO KEEP — `git checkout -- <file>` cost hours of uncommitted
  work.** I used it to revert a temporary A/B experiment on `web/index.html`,
  and it discarded **every uncommitted change in that file**, which was the
  whole regional-naming front end. It was reconstructible only because the
  edits were in conversation context. **Commit before running any experiment
  that ends in a revert**, or apply the experiment to a copy. The rest of the
  session's A/Bs were run only after committing, which is why they were safe.
- ⚠️ **deck.gl: a CONSTANT accessor compiles to a uniform; a FUNCTION accessor
  builds a per-vertex attribute buffer.** `getLineColor: f => …` over the
  boundary set (four large counties) cost enough per layer update to blow
  `verify-temporal.js`'s 4 s click timeout under SwiftShader.
  **Hoisting the arrow out of the layer literal fixes only HALF** — stable
  identity stops the per-rebuild churn (5,284 ms → 347 ms on one metric switch)
  but the attribute buffer is still paid every update, and the suite stayed red
  **3/3**. Fix: **one layer per stroke, constant accessors**
  (`boundaryLayer()`). Style a new shape by adding a layer, never an accessor.
- ⚠️ **Bisect; do not guess.** Label count (16 vs 7) and the new geometry were
  each A/B'd and **cleared** before the accessor was found — both were the
  intuitive culprits and both were wrong. Master ran **5/5 green** throughout,
  which is what made "it's just SwiftShader flake" untenable.
- ⚠️ **A doc figure and a verify-script literal can disagree for weeks with
  nothing comparing them.** Same class as S101's find, one layer down.
- ⚠️ **A verify counter can silently stop covering the thing it names.**
  `places: d.filter(x => x.prio === PRIO_PLACE)` meant "towns" — every new tier
  would have read as absent and still passed. Now counted by `x.ref` with a
  per-tier breakdown.
- ⚠️ **Two suite assumptions were retired deliberately, not loosened:**
  "exactly one reference text size" and "exactly two sizes" both encoded the
  single-tier design. The invariant kept is the **ordering** — regional text
  never outweighs a hood name.
- ⚠️ **`_region_anchor` is not a centroid and must not become one.** County
  centroids sit **27–58 km** from Edmonton's centre (Parkland's is 58 km west),
  so centroid labels land off the default camera and simply never appear.
- ⚠️ **Alberta publishes the Industrial Heartland UNNAMED** — one 590.7 km²
  MultiPolygon in `boundaries/resource_designated_industrial_zone`, **no name
  field**. Identified by overlap: Sturgeon 171.8 / Strathcona 134.3 /
  **Edmonton 53.2** / Fort Saskatchewan 29.5 km². Guarded by `ZONE_MIN_KM2`
  because there is no name to assert against.
- ⚠️ **53.2 km² of the Heartland is INSIDE Edmonton**, so it is *not* a clean
  "regional infrastructure Edmonton doesn't tax" shape. That framing holds for
  the airport and Nisku (both Leduc County). **Do not narrate the Heartland as
  one.**
- ⚠️ **The reference layer is too generalized to settle adjacency.**
  `BOUNDARY_SIMPLIFY_M = 100.0` and `_largest_polygon` keeps only the biggest
  part, which is enough slop to manufacture touching. It CAN settle area and
  the big directional facts (**all four counties abut Edmonton** — 16–22.6 km
  of shared edge each, far above the noise floor). It CANNOT settle
  Devon/Beaumont. Leduc city (3.3 km) and Spruce Grove (8.9 km) genuinely do
  not touch.
- **Nisku is a HAMLET** — Alberta publishes hamlets as points only (sublayer 7,
  `CULPT_NAME`); no legal polygon exists to draw. The airport is fetched from
  Overpass **by IATA code**, not name (`iata` is stable, `name` gets edited),
  and needs a **tight bbox** — a province-wide aerodrome query 504s.
- **Playwright/node quirk:** `playwright` resolves from
  `tools/profiling/node_modules`, i.e. from the **script's own directory**, not
  the repo root. A probe script must live in `tools/profiling/` to `require` it.
