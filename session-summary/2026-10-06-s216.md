## 3. Technical Learnings
- **LRT routes `rpjw-4jft` now has 3 features, not 4.** The City dropped `HER` (the heritage streetcar). `EXCLUDED_LRT_ROUTE_IDS` excluded it anyway, so nothing published changes. The SOURCES comment still says "4 routes".
- **GitHub concurrency `queue`** (docs re-read this session): `single` (the default) cancels the pending run when another queues; `max` keeps up to 100 pending, runs them FIFO, and is valid with `cancel-in-progress: false`.
- **Panel renderers can be driven headless.** `renderServiceCost(p)` reads `state.svcDriver`, and setting it directly needs no layer rebuild. `state.services` is the set of ticked services, not the set on offer. Filter offered drivers with `FULL_BUILD || SERVICES[k].pub`.
- Before reading a panel's text, insert a space before every tag. Otherwise adjacent cells fuse into one token ("$1,2340.0%").
- **Rendering a colour override:** `SET_ASIDE_COLOR` is a `const`, so to try candidates, serve a copy with `let` and reassign it.
  - deck.gl's `updateTriggers` include `state.ramp`, so toggling the ramp away and back re-evaluates fills. Toggling within one `evaluate` is batched and does nothing; put ~1.5 s between the two clicks.
  - My first comparison render was four identical panels. I only noticed because I looked at the image.
- **Arterial grey vs cividis:** `ARTERIAL_COLOR` (116,120,132) is ΔE2000 4.3 from the cividis ramp; default and glow are ~28. Logged as an open TODO and not rendered.
- **Playwright from the scratchpad:** `require('playwright')` fails outside the repo. Use `NODE_PATH=$(pwd)/node_modules:$(pwd)/tools/profiling/node_modules`.
- The CODEMAP hook only fires on Edit/Write. After editing `web/index.html` via a python script, run `.venv/bin/python tools/codemap.py`.
- `pkill -f "http.server …"` killed its own shell again (exit 144); the memory `pgrep-watchers-match-themselves` applies. Harmless here because it was the last command.
- `tools/todo_archive.py` only archives `- [x]` items. A `###`-heading item has to be moved by hand: body to `docs/TODO_archive.md`, plus a `## Done` line.
