## 3. Technical Learnings

- ⚠️ **`gh repo create --public` is DENIED by the auto-mode classifier**
  ("Create Public Surface"); `--private` went through. Both new repos are
  therefore **private** — flip by hand if a public template is wanted.
- ⚠️ **`gh repo create --source=. --push` fails on this box**: the remote is
  set to HTTPS and there is no credential helper → *"could not read Username
  for 'https://github.com'"*. The repo IS created and the template flag IS set;
  only the push fails. Fix: `git remote set-url origin git@github.com:<o>/<r>.git`
  then push. `edmonton-tax-viz` has always used the SSH remote.
- ⚠️ **A bare `python3` on this box is 3.6.8** (`/usr/bin/python3.12` exists
  separately). A `venv` built from it cannot install a modern pinned pytest,
  and under `set -e` the script dies before anything after it runs — which is
  how the memory seed silently never executed. `bootstrap.sh` now probes
  `$PYTHON`, 3.13, 3.12, 3.11, 3.10 and errors with instructions if none.
- **The doc-citation guard caught its own docstring.** `check_doc_citations.py`
  cited `DATA.md §5` as an *example*, the template's `DATA.md` has no numbered
  sections, and the guard failed the template's own CI check. Real finding,
  not a false positive — the example was rewritten.
- **`grep -c` counts LINES** (S172 said the same; it cost a wrong count again
  when measuring project-specificity). Use `grep -o | wc -l` or python.
- **Auto-memory paths are derived from the project directory**
  (`~/.claude/projects/<abs-path-with-slashes-as-dashes>/memory/`), so a new
  repo starts with an empty memory. `bootstrap.sh <sibling-memory-dir>` copies
  only `type: feedback` files and rebuilds `MEMORY.md` from frontmatter
  (stripping the quotes some `description:` values carry).
- **A sed-driven multi-file genericize pass belongs in a scratchpad python
  script, not a heredoc**: the first attempt put triple-quoted Python inside a
  bash heredoc and died on a `SyntaxError` at the nested docstring.
- Important locations: `/home/opc/cc-data-project-template`,
  `/home/opc/alberta-regional-viz`, `/home/opc/research/` (both reports, dated),
  `~/.claude/projects/-home-opc-alberta-regional-viz/memory/`.
- Memory written this session: `cc-data-project-template.md` (`type: project`)
  + its `MEMORY.md` line, covering both repos, the decisions, and the
  public-repo denial.
