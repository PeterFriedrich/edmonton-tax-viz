## 3. Technical Learnings
- ⚠️ **deck.gl's `getTooltip` `{className}` does not restyle the tooltip.** Its defaults are written inline. Override them with a `style` object in the return, or with `!important`.
- **The probe instrument mutated nothing, but it measured a cell that could not differ.**
  - M2's first pass used Downtown, whose revenue mix holds only theme-invariant colours, so it reported 0 stale.
  - Re-run with `HOOD="EDMONTON SOUTH CENTRAL"` / `"ANTHONY HENDAY MISTATIM"` (Future/rural plus unzoned), M2 confirmed.
- **Public-build gates silently drop hash states.** Uses, Infill and `#budget-btn` are full-only, so the hash or click falls back to Money. Print `state.view` per screenshot.
- **The Read tool renders PDFs.** `page.pdf()` plus Read is a print-path test on this box, which has no rasterizer.
- **Chromium auto-dark can be emulated in headless Playwright:** `--enable-features=WebContentsForceDark --blink-settings=forceDarkModeEnabled=true`. Force dark repaints at paint time, so computed styles are unchanged and only screenshots show it.
- **A stale `http.server` from another session's deleted scratchpad held port 8947.** The md5 check caught it. Use a fresh port; it was left alone.
- **The arithmetic reuses `tests/test_light_ramps.py`.** Import it with `sys.path.insert(0,'tests'); import test_light_ramps as T`; it reproduces S218's 14.5 / 8.9 / 7.3% exactly.
- **ARCHITECTURE.md's verify-tier row is stale** (F10). There are 44 scripts, and CI runs smoke, blurbs and url-state.
