## S66 — 3. Technical Learnings
- **THE gotcha that bit the layout restructure:** `#coloradj`/`#lens`/`#layers` carry
  `class="panel"` (`position:absolute`). The reset `#controls > div { position: static }`
  only covers DIRECT children. Moving them into `#optpanel` left them absolute →
  overlapping pile-up. Fix: `#optpanel .panel { position: static; right:auto; top:auto }`.
  **Any future nesting of a `.panel` element needs a position:static reset.**
- **Verify-by-id is the safety net:** every per-view show/hide uses `getElementById`,
  so elements can be re-parented freely as long as ids are preserved — `applyView`,
  `syncDevControls`, etc. never break. This is why the big DOM move was low-risk.
- **Two-build model, confirmed against `build_site.py`:** both builds regenerate every
  deploy from ONE source (`web/index.html`'s `DEFAULT_BUILD` literal); `/full/` shares
  root `data/`+`vendor/` via `<base href="../">`; **default is public** so the failure
  mode is "forgot to flag → leaked to public," not drift.
- **`deploy.yml` fires on `web/**` push to master = live deploy.** This is why UI work
  goes on branches → PR (Peter merges = go-live). Docs (README/`docs/`) push straight
  to master, no deploy (path filter).
- **Headless verify quirks:** the emulator font lacks U+24D8 (ⓘ renders as tofu) — used
  U+25BE/U+25B4 (▾/▴) carets instead. `verify-labels` needs ~60s (zoom re-cull step);
  a 40s `timeout` kills it mid-run (it's fine, just slow). `pkill -f "http.server 8931"`
  in a `&&`/`;` chain returns exit 144 and can abort the compound command — run it alone.
- **Key locations (current master + #84):** `web/index.html` — `#optpanel`/`#opt-fold`/
  `#opt-body`/`#opt-pres` CSS (~L36–75), the `@media (max-width:640px)` seam (~L219–249),
  `#a11y` bottom-right (~L155), the fold + title-tap JS (~L3218–3232), `applyView`
  (~L2919), the uses-button `|| !FULL_BUILD` guard (~L3264 on master). `scripts/build_site.py`;
  `tools/profiling/shot-mobile.js` (probe id list).

## S67 — 3. Technical Learnings
- **THE testing gap (now guarded):** the functional `verify-*.js` suite actuates
  controls with `page.$eval(sel, b => b.click())` — a JS `.click()` that **bypasses
  `pointer-events` and z-order**. So a visible-but-unclickable control passes every one
  of them. That's how the S66 refactor shipped dead buttons to production. **Run
  `verify-controls-clickable.js` after ANY control-chrome/CSS refactor** — it
  real-hit-tests every visible control per view. (Memory: `verify-scripts-bypass-pointer-events`.)
- **`.panel` = `pointer-events:none`; a flip list re-enables the real pods.** Any time a
  `.panel` element is re-parented, it needs BOTH a `position:static` reset AND a
  `pointer-events:auto` restore (the `#optpanel .panel` rule now does both).
- **Camera model:** two framing presets, both `map.easeTo(HOME | HOME_2D, {duration:700})`.
  `#center2d.flat` (gold) is toggled by a `map.on("pitch", …)` listener keyed off
  `map.getPitch() < 1`, so it stays correct even under manual tilt-drag.
- **Env quirks (recurring):** (a) `pkill -f "http.server 8931"` returns **exit 144** and
  aborts a compound command — run it alone. (b) `node tools/profiling/…` must run from the
  **repo root**, not `web/` (a `cd web` to start the server leaves the dir wrong → MODULE_NOT_FOUND).
  (c) swiftshader animates `easeTo` slowly — verify scripts **poll until settled**, don't
  fixed-sleep. (d) top-level `const` (e.g. `HOME`, `map`, `state`) IS reachable by name
  inside `page.evaluate` (global lexical env), but is NOT on `window`.
- **Key locations (current master):** `web/index.html` — clickability fix L73; `HOME`/`HOME_2D`
  L465-466; map constructor L1370 (uses `HOME.*`); camera CSS L184-198 (`#botleft`/`#viewbtns`/
  `#center2d`/`#recenter`); DOM L440-445; JS wiring ~L3262-3277. Verifies:
  `tools/profiling/verify-{center2d,recenter,controls-clickable}.js`.
