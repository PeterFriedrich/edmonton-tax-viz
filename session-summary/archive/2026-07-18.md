## 3. Technical Learnings
- **The Glass-grid metric pattern is proven 5× now** (value/revenue/res/age/
  nonres): a `has_X` guard in `build_value_grid` ground path + `_cell_lot_metrics`
  eligible path + `build_hood_lot_acres` + append to the payload column list
  (LAST, stable prefix) + one `gridData.columns` entry + one `METRICS` entry.
  `nonres` rode it with zero new render code (unlike age, which needed its own
  linear scale/layer).
- **`NONRES_RATE_LABELS` is DERIVED from the label→rate-class map**, not
  hand-listed — `{label for label,rc in ASSESSMENT_CLASS_TO_RATE_CLASS.items()
  if rc == "Non Residential"}`. So a future non-res assessment label is caught
  automatically (and the unmapped-label hard error still guards new labels).
- **Permit `building_type` codes DUPLICATE across unrelated types** — `Parkade
  (490)` vs `Engineering (490)`, `Mixed Use (522)` vs `Office Complex (522)`.
  Enumerate industrial by FULL STRING, never by the `(NNN)` code (same rule the
  residential set already follows). A test pins Parkade-490-not-industrial.
- **Industrial per-acre is tiny (~0.01–0.02)** — the legend's `toFixed(1)` would
  render "0.0+"; added a `clamp < 1 ? 2dp` branch to the dev-legend max. `fmtDev`
  already did 2dp below 1 for the tooltip.
- **Infill isolation pattern** for a dev-only metric: reset `state.devMetric` to
  a residential column on entering Infill (`applyView`) + hide the button
  (`syncDevControls`, gated on `state.hasIndPermits`), so all existing infill
  code (which reads `devCol()`/`state.devMetric`) works unchanged — no
  per-callsite clamping. `devGridActive()` = `state.devGrid && devGridData &&
  !devIndustrial()` centralizes the "industrial = choropleth only" gate.
- **`gh pr view N --json state` per PR, ALWAYS** — Peter merged #75 and #77
  mid-session; #77 into a non-master branch, which is the sneaky variant (the
  head branch keeps accumulating, a later local commit can strand). `gh pr list`
  showed both #76/#77 while #77 was already merged into #76's base.
- **playwright lives in `tools/profiling/node_modules`** — screenshot/verify
  scripts MUST be run from repo root with the `tools/profiling/` path (a script
  copied to `/tmp` or repo-root-only can't resolve `require('playwright')`).
- `pkill -f "http.server 8931"` exits 144 — harmless (kill worked).
