## 3. Technical Learnings
- **verify-theme needs the BUILT tree**, made by `.venv/bin/python scripts/build_site.py --out <scratch>` (24 MB, ~5 s). `web/` has no `dev-build-full/`, so `--serve web theme` crashes after 54 checks.
  - ⚠️ On 11-04 I misreported a direct run against `web/` as "54 PASS, 0 FAIL" because I only counted PASS/FAIL lines.
  - A whole run takes ~490 s; run it alone.
- **Count checks AND read the exit/crash, not just PASS/FAIL lines.** That's the same lesson as the runner's "exit code is the backstop" comment.
- A `/code-review` launched as a synchronous fork returns no usage line. Only background runs report tokens and time: 57k–75k tokens, 37–60 s.
- In auto mode, `gh pr comment` was denied as "[External System Writes]" even though `.claude/settings.local.json` allows `gh pr *`. The command was a compound with a heredoc. `gh pr create` and `gh pr merge` passed.
- `.claude/settings.local.json` allows `.venv/bin/python` by ABSOLUTE path only. A relative `.venv/bin/python …` goes to the classifier.
