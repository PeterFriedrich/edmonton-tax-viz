## 3. Technical Learnings
- **deck.gl 9.0 tooltip mechanics** (vendored `deck.gl-9.0.38.min.js`):
  - `onAdd` writes `U8` defaults inline (`#a0a7b4` on `#29323c`, `padding:10px`).
  - `setTooltip` then `Object.assign(el.style, e.style)`, so empty strings remove the inline values.
  - The widget is reachable as `overlay._deck.widgetManager.getWidgets()`, id `default-tooltip`.
- **Automation forces dark:** the head script picks dark when `navigator.webdriver` is set. To render light, set `localStorage.theme`; `colorScheme: 'light'` alone is ignored.
- **`verify-theme.js` takes a BASE URL** (`http://localhost:PORT`), not `index.html`. Given a page URL, it fails with "Cannot read properties of null (reading 'hidden')".
- **`tests/test_theme_tokens.py::_rule()` takes the FIRST `:root[data-theme="light"] {`.** A second rule with that selector (even one line) breaks 4 tests. Put new declarations inside the existing blocks.
- ⚠️ **I wiped an uncommitted fix with `git checkout -- web/index.html` while restoring a mutant** (the commit-before-falsifying memory, again). Caught at once and redone. After that I committed a `wip` before every mutant and amended it later.
- **`check_decisions_log.py` treats "the same day" as a supersession reference** and demands the same-day rows be marked. Reword it, e.g. "on 2026-10-09 as well".
- A themed() scanner must skip `themed():` in the new error message, hence `\bthemed\((?!\))`.
