## 3. Technical Learnings

### The audit's five findings (full text: `docs/FINDINGS_vacuous_guards_r2.md`)

**R1 — HIGH — a served column can go ALL-NULL and the whole publish path stays
green.** `check_served_columns.py` counts **key presence** deliberately (a null
is a legitimate "no value for this hood" — the four `*_per_lot_acre` columns are
null on the seven set-aside hoods by design). But a failed join or a renamed
upstream field **does not drop the key** — the pipeline writes the column and
fills it with nulls.

- **Falsified against the real served file:** `res_revenue_per_acre` nulled on
  **406/406** → guard **exit 0** *and* `verify-smoke.js` **ALL CHECKS PASSED** on
  the public build. A blank public lens would have published, green.
- ⚠️ **Why the render gate is structurally blind, not merely unlucky:** the money
  legends are **static literals** (`legendMax: "$30k+"`), and `viewTooltip`
  **omits** a null row rather than printing `NaN`, so `every hood renders a
  readout — 406 rendered` still passes. `check_revenue_deltas` reads
  `total_revenue` only.
- `revenue_per_acre` all-null reddened only via the **ratio** view's `$NaN` — a
  different assertion in a downstream view, which the brief classes as itself a
  finding.

**R2 — HIGH — the merge gate's guards can be neutered at their exit line with
800 tests green.** Four mutations, each **800 passed**: `check_cost_copy` drift
`return 5 → 0`; `check_value_anchors` and `check_temporal_years`
`EXIT_DRIFT → EXIT_OK`; and `tests.yml` **with the cost-copy step deleted**.
⚠️ **Every test for those three guards exercised the DETECTOR; none reached
`main()`**, which is the only thing CI reads — run 1 gave `check_cost_copy` 13
tests and all 13 stop one line short of the exit code. `test_ci_workflows.py`
pinned pytest's membership only: **2 of ~14 guard steps.**

**R3 — MEDIUM — smoke B8 examined its rows through a selector and filtered the
misses OUT**, so renaming `data-service` left it comparing an empty list and
printing PASS. §1's "N passed is not a measurement", inside the publish gate.

**R4 — a 75-constant mutation sweep, triaged.** 58 green, but **do not quote
that as a defect count**: 6 unpinned **guard bands** (`HISTORICAL_TOLERANCE`

### Method notes that generalise

- ⚠️ **`git checkout -- <path>` between mutations REVERTS AN UNCOMMITTED FIX, so
  the mutations after the first measure nothing.** My first falsification of the
  #364 gate red two tests because the step was **ABSENT**, not because of the
  mutation. **Commit the change, then falsify against the committed state.**
  Caught only because one mutation reddened a test it had no business touching —
  a dropped `/full/` line cannot affect a *position* pin. **The tell is a
  falsification that reds the WRONG check**, which is exactly what the brief §5
  says to treat as a finding.
- ⚠️ **`0 or fallback` is a bug when 0 is the value.** The first draft of the
  exit-label test read `getattr(mod, "EXIT_OK", None) or getattr(mod, "EXIT_ALIGNED")`;
  `EXIT_OK` **is 0**, so it fell through and raised `AttributeError` instead of
  comparing. Use `getattr(a, x, getattr(a, y, None))`.
- ⚠️ **An unquoted heredoc eats backticks.** Three backticked filenames were
  command-substituted out of a `TODO.md` line (`in \`check_served_columns.py\``
  → `in ,`). **Use `<<'EOF'`, or write the payload to a file first.** Repaired
  and the other three docs scanned.
- ⚠️ **`python -m http.server --directory X` does NOT chdir**, so `/proc/<pid>/cwd`
  is the launch directory and a cwd check aborts four *correct* runs as "WRONG
  SERVER". Start with `(cd X && exec python -m http.server P) &`. **The memory
  `confirm-the-server-you-measure` has been corrected.**
- ⚠️ **Confirm the mutated element is in the check's POPULATION.** The first B8
  falsification hid the **roads** row — the one service with no `plane.col`,
  which B8 excludes by design — and its PASS said nothing. **Now a rule in the
  brief §5.**
- **`build_site.py` fails under the box's system `python3` (3.6, no
  `capture_output`)** — use `.venv/bin/python`. CI runs 3.12.
