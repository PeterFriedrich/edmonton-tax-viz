## 3. Technical Learnings

### Verifying a merge is not ceremony — it found the defect
#261 was green, merged, on master, and **not live**. Nothing was red. The
project's own rule (*check `gh run list` after any `web/**` merge*) did not
cover it, because the change was not under `web/`.

### Writing out a proposed remedy is how you falsify it
The audit's own F1 proposal would have reintroduced the loss from the other
side. It survived being written into a findings doc and a TODO item, and only
died when I went to implement it. **Propose-first has a second payoff beyond
Peter's approval: the proposal is a testable artifact.**

### Replacing a proxy with a measurement is necessary, not sufficient
Ask what the measurement's **candidate set** is and who controls it. The FIR
guard measures real parcels against a real external filing and is still blind
for months a year.

### Reversibility, not correctness, should size a gate
"Inconclusive → proceed" is right for regenerating `web/data` and wrong for a
permanent capture. They shared one gate. **That is the reusable half of F1.**

### Falsify a regression test against the DEFECT, not the signature
The first falsification failed with `TypeError` (no `confirmed` kwarg), which
proves nothing. Giving the pre-fix function the new keyword and leaving it
otherwise untouched made it fail on `assert (2026 is None)` — on having
archived where it should have refused.

### Environment quirks (this box) — all still true
- ⚠️ **A stale `http.server` can squat a port across sessions** and serve a
  different tree. Use a fresh port; a result contradicting readable markup is a
  wrong-target result.
- ⚠️ **`--write-archive` run LOCALLY re-captures from `data/raw/`** — this box's
  CSV is 2026-08-09 and the committed archive is fresher, so a local run
  produced a **193-insertion/189-deletion downgrade**. Restored; now warned in
  the argparse help. **CI owns that flag.**
- ⚠️ **Playwright lives in `tools/profiling/node_modules`** — a script in `/tmp`
  cannot `require('playwright')`.
- ⚠️ **Run verify scripts ONE AT A TIME** on this 4-core box.
- ⚠️ System `python` is 3.6.8 — use `.venv/bin/python`. HTTPS `000` is the CA
  bundle; use `certifi`.
- ⚠️ `_site/` is build output, **not gitignored and never committed**.
