## 3. Technical Learnings
- **Auto mode classifies a branch-protection PATCH as "CI Bypass" and denies
  it,** even to make protection stricter. Manual mode allowed it.
- **`url-state` is safe to require.** The aggregate job reports `url-state`
  success on PRs that don't touch `web/` (it was checked on #646 and #649), so
  docs PRs are not blocked. GitHub Actions `app_id` is 15368.
- **Falsifying `verify-about`'s link branch:**
  - `sed` the script into `tools/profiling/_mut_about.js` (it needs
    `node_modules`), replacing `page.request.get(l.href, ` with a stub URL;
  - point it at a `ThreadingHTTPServer` that returns the status taken from the
    path (`/0` sleeps 30 s to force a timeout).
  - The timeout case takes about 5 min a run: 20 s × 4 links, plus the page.
- **Alberta Education's school XLSX:**
  - URL: `https://education.alberta.ca/media/1626669/authority_and_school.xlsx`;
  - the header is on row 3 (`header=2`);
  - `Extract Date` is a per-row timestamp;
  - `School City` is a mailing field, not a location.
- **A Socrata catalogue search covers only Edmonton's portal.** Any
  "absent from open data" claim also needs open.alberta.ca's CKAN
  `package_search`.
- **The Wayback CDX API returned 504 or `[]`** for `data.edmonton.ca/api/views/…`.
  There is no history of `Period of Coverage` to check.
- ⚠️ **I hit the `pkill -f` self-match again:** `pkill -f "until grep -q"`
  killed its own shell (exit 144). Use `kill <pid>`.
- **Foreground `sleep N && …` chains are blocked by the harness.** Use
  `until <cond>; do sleep 5; done` instead.
