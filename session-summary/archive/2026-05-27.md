## 3. Technical Learnings

- **Boundaries dataset ID:** `65fr-66s6`, NOT the ArcGIS link in old DATA.md. Socrata GeoJSON endpoint: `https://data.edmonton.ca/resource/65fr-66s6.geojson?$limit=50000` (must escape `$` in shell — use single quotes with curl).
- **`lot_size` in `dkk9-cj3x`** is city-provided (not computed), units are sq metres, repeated per condo unit — summing across units overcounts land area. This is why Approach B was rejected for Phase 1.
- **Neighbourhood name mismatches:** 8 fixable via correction dict (in `src/join_and_calculate.py`). 3 genuinely unresolved — see `data/DATA.md` Name Matching section.
- **Real data pipeline output:** 439,723 rows → 408 neighbourhoods → 405 with `value_per_acre` after join. 46 zero-value rows dropped, 3 tax-exempt flagged, 3 assessment neighbourhoods unmatched.
- **`output/` directory** already exists in repo root — no need to create.
- **Choropleth outlier issue:** Downtown ($13.8M/acre) and Wîhkwêntôwin ($9.8M/acre) dominate the colorscale. Consider `scheme='quantiles'` or log normalization before publishing.
