## 3. Technical Learnings

### A guard that is written but not invoked is documentation
S119 built the right detector and left it unwired, and the *same* PR removed the
old guard's ability to ever say "aligned". Net effect: a week of green runs with
**zero** roll-year confirmation. **Shipping a guard is two steps — write it, and
put it in the path that runs.** Grep the workflows for a new script's name
before calling it done.

### A test's imports are part of the CI contract
`import yaml` in a new test is a dependency of the weekly publish, because
`pytest tests/` gates it. `PyYAML` was in `requirements.txt` but not
`requirements-ci.txt`; `jupytext` happens to pull it transitively, so it might
have passed by luck. **Check a new test's imports against `requirements-ci.txt`,
not against what your venv happens to have.**

### "Self-contained" has three readings, and they are different work
Verified-and-CI-gated / standalone-and-portable / exploration-only differ in
audience, drift exposure and runtime cost. Asking cost one question and avoided
building the wrong artifact twice. Peter chose **standalone** knowing it rots —
recorded with its rationale in `DECISIONS.md` 2026-08-26.

### Re-measure before quoting a documented figure — the counts held, the dollars did not
`SPEC_temporal.md` §0's **account** counts reproduced exactly a month later, but
**$2.93B → $3.008B** and Downtown **53% → 48.4%**, because the control is the
current roll and *the roll rolled to 2026*. A figure derived from a moving
control has a shelf life even when the defect is frozen.

### The validator checks colour; only looking checks layout
Rendering each chart caught two label collisions in the exemption notebook (a
value label crossing the 100% reference line, an annotation overflowing the
axes) and a legend sitting on top of its own markers. `validate_palette.js`
passed throughout.

### ⚠️ This box has almost no fonts, and it will mislead you
`fc-list` → **Cantarell, DejaVu Sans Mono, Fixed**. Any HTML asking for
`system-ui`/Helvetica/Arial **screenshots as monospace here**. Verify the
computed `font-family`, and force `Cantarell` via `addStyleTag` for a truthful
preview. The published pages are fine; the screenshots were not.

### Playwright lives in `tools/profiling/node_modules`
A screenshot script must be run **from `tools/profiling/`** or `require` fails.
`cd` in a compound command also resets the shell cwd between calls here.

### Two small API gotchas, both real
- **`open.alberta.ca` 403s urllib's default User-Agent.** Set one. `requests`
  works because it sends its own — which is why the earlier probe passed and the
  notebook then failed.
- **Socrata URLs must be `urlencode`d** — a raw `count(*) as n` in `$select`
  raises `InvalidURL` on the space.
