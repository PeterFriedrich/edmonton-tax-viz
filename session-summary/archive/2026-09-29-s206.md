## 3. Technical Learnings
- **Teardown cost by action, after a page drew a grid:**

  | Action | Cost |
  |---|---|
  | `reload` / `goto` on the same page | 13–28 s |
  | `page.close()` | 0.01 s, but the next `newPage()` takes 6–8 s |
  | final `browser.close()` | pays whatever teardown has accumulated |
  | `launchServer` + `server.kill()` | 0.03 s |

- **A plain cold load reaches network-idle in ~1–2 s.** Most scripts then sleep another 3.5–4 s.
- **The runner reports "0 checks" for 8 scripts.** It counts only `^PASS` / `^FAIL` lines, and `verify-budget-panel` indents its `  FAIL` lines. Those 8 still gate by exit code, except the 4 assertion-less ones, which always exit 0.
- **`verify-blurbs` refuses the full build by design.** The runner reports that as FAIL.
- **Measure through a `NODE_OPTIONS=--require` preload, not by editing scripts.** Every script uses `require('playwright')`, which resolves to `tools/profiling/node_modules/playwright`, so the preload can patch `chromium.launch`.
- **The scratchpad helpers are ephemeral:** `perpage.js`, `perpage_w.js` (which also totals `waitForTimeout`), `phase.js`, `teardown.js` and `next.js`. The preload's text is preserved in the findings doc.
