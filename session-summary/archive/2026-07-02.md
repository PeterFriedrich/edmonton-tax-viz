## 4. Technical Learnings (don't re-derive)

**deck.gl facts that shaped the design:**
- **`opacity: 0` is a fade, not a removal** — the layer still tessellates,
  draws, PICKS, and auto-highlights. Hover resurrected ghost prisms; weak
  GPUs paid full cost. True removal = drop the layer from the stack.
- **Picking ignores opacity** → an invisible prism always beats the roads
  under it → road-feature tooltips could never fire. Hood tooltips carry the
  road story instead; ground layers are non-pickable.
- The picking A/B (Peter felt no difference) exonerated the picking pass as
  the perf culprit.

**Geometry perf ceiling:** most remaining vertices are path ENDPOINTS at
street junctions — no simplify tolerance removes them; linemerge only welds
degree-2 joins. Next lever if ever needed: zoom-dependent rendering (real,
but third in line — noted in SPEC). Peter's laptop = Intel HD 4400 (Haswell
2013, hardware WebGL confirmed via about:support) — treat as the low-end
proxy for public visitors.

**Ratio-view decisions (locked, but see the caveat):** Peter was AFK for the
AskUserQuestion, so the four calls went with my recommendations —
colour+height encoding (height linear), "5% transparency" read as 5% opacity,
5 m/acre artifact floor, view-buttons+slider. **All flagged to Peter in chat
afterwards; he approved the views on-device before merge.** Tunables most
likely to want taste: 5% default, floor value, ratio wording.

**Log colour for the ratio is data-forced, not stylistic** (FINDINGS §6.4).
The anchors are computed at page load from the served GeoJSON so they track
weekly refreshes — no committed constants to go stale.

**Headless quirks (tools/profiling):** swiftshader needs ~60 s before
screenshots with the roads layer on (`page.screenshot` flush can take
minutes; patience beats debugging). `shot-click.js` (committed) does
click-then-shoot. Node module resolution requires running from
`tools/profiling/`; heredoc `python` needs the conda env or `python3`.

**Web-export shape (src/load_roads.py):** access dissolved per-hood (carries
`v` = road_m_per_acre), arterials citywide single feature (`n` null);
`v` computed BEFORE display thinning; sliver drop logged, never silent.
