## 3. Technical Learnings
- **deck.gl: a new `material` (or any prop) does NOT reach a GeoJsonLayer's sublayers unless an `updateTriggers` entry changes.** The parent showed the new `specularColor` and the `-polygons-fill` sublayer kept the old one. Every themed layer therefore needs `state.theme` in some trigger, not only those with accessor functions.
- **Screenshots of this app are not deterministic headless.** Two runs of unchanged master differ by up to ~580 px (label cull and timing). For "dark unchanged", hash every layer's colour attributes and props instead.
  - Exact, with one fix: label layers' `instanceColors` vary in length run to run, so compare their *set* of distinct RGBA, not the array.
  - Script: scratchpad `coldump.js`, not committed. The method is in the #679 body.
- **deck's default colour for unused channels is opaque black `[0,0,0,255]`** (line colour on fill-only layers, fill on stroke-only). It collides with any themed opaque black. `verify-theme.js` matches black only in label layers.
- **Development defaults to the 100 m grid**, so `#view=development` never draws the neighbourhood `dev-plane`; it needs `&detail=hood`. No hood has a null dev value, so `dev-plane` draws only ramp colours. ⚠️ The theme probe cannot see a missing trigger there until ramps are themed (phase 2 must extend the probe to ramp stops; noted in UI.md).
- **The light-mode costing that held it was right about chrome-only and wrong about difficulty.** There are no basemap tiles (the backdrop is one `background-color`), and `RAMPS.*` already carry `bg` / `edge` / `setAside`, swapped live by `applyPalette`.
- `pgrep -f "http.server 8957"` from a `bash -c` whose own command line contains that string matches the shell. Use `pgrep -f "http.server 895[7]$"`, then check `pgrep -af` afterwards (memory `pgrep-watchers-match-themselves`, again).
- DECISIONS rows are markdown table cells: a literal `|` in prose ("Revenue | Value") splits the row, and `check_decisions_log.py` then reports "names no test". Escape it as `\|`.
- Session-summary archiving sorts by name: `2026-10-05-s215-report.md` sorts before `2026-10-05-s215.md` (`-` < `.`).
