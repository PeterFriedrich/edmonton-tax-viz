## 3. Technical Learnings
- ⚠️ **A `:has()` on `body` slows every interaction.**
  - `body.mills:not(:has(#temporal.open)) #title` made `verify-temporal`'s 4 s clicks time out in 4 of 4 runs, each time on a DIFFERENT control. Without it, 0 of 2 failed; master was 1 of 1 clean.
  - A rotating failure pattern is not proof of flake: A/B the suspect rule before calling it noise.
  - Recorded in `docs/UI.md` → Blurb box.
- **`verify-millrates` "pod stays one line per row" measured border-box height ≤ 50.**
  - The new box padding pushed a 45 px pod to 55 px. It now measures CONTENT height (`text h=…`).
  - A 360 px mutant still reds it (57).
- **The cascade order trap in `styles.css`:** a `@media (min-width: 641px)` block placed early lost to the later base rules (`#millrates { width: 400px }`, `#temporal { left: 22px }`). Desktop overrides must come after their base rules.
- **MapLibre `background-pattern`:**
  - It is pinned to the ground plane, so it tilts in 3D.
  - The cell grows 16 → 27 px across each zoom level and snaps back at the next whole zoom (measured flat, quarter-zoom steps).
  - `addImage` takes non-premultiplied RGBA: the line pixels measured +14 / −11, matching the alpha.
- **A MapLibre layer added in a `map.on("load")` handler registered before `boot`** lands under deck's interleaved layers. `getStyle().layers` order: `bg > bg-grid > city-mask`.
- **Equal ΔE2000 ≠ equal visual weight across themes:** thin dark lines on near-white read stronger than light lines on near-black.
- **This box renders WebGL on the CPU (SwiftShader).** Each frame takes ~0.5 s, even with deck's layers removed. So only on/off A/Bs are meaningful here, never absolute timings.
- **`pgrep -f` waiters matched themselves again**, with the memory loaded. Memory updated: chain the dependent steps in ONE `run_in_background` command and let the harness notify you; never poll.
- **`themed()` colours must be drawn by a deck layer**, or `verify-theme`'s "every themed colour is drawn" fails. That is why `GRID_INK` is a plain `{dark, light}` object.
- **One-state `verify-theme` copy for mutants:** `scratchpad/vt-one.js` (STATES trimmed, `readerPaths()` call removed). It always fails "every themed colour is drawn" by construction; ignore that line.
