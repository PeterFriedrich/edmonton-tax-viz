## 3. Technical Learnings
- **`verify-smoke.js:310` C-family tooltip sweep is VACUOUS since 2026-08-02** (b99af11). `viewTooltip()` returns `{className, html}`, and the regex runs on the object, so it only ever sees `"[object Object]"`. Proved with a NaN mutation: 340 of 406 tooltips carried NaN, and C-money passed. Every other `tools/profiling/` caller uses `.html`, and `audit-controls-diff.js` even documents this trap.
- **C9/C10 test the helpers over columns, not the rendered surfaces.** They stay green over live bypasses:
  - The ratio tooltip's local `const money = v => "$" + Math.round(v)...` prints UNIVERSITY OF ALBERTA FARM's band as `$0 to $5,115`; Money prints `<$1`.
  - The ratio floor message `(${p[d.col].toFixed(...)})` prints HERITAGE VALLEY AREA's road as `(0.0)`.
- **A data change that lowers small values must re-run the readout floors.** `fmtBike`'s no-floor exemption rested on "zero base rate" (DECISIONS 2026-09-20). The split puts KING EDWARD PARK at 0.0046 m/acre, so it will render `0.00`.
- `<` in un-escaped tooltip HTML is safe (`<$1`, `<0.1` render as text). But a tag-stripping regex (`<[^>]+>`) eats them. Read tooltips via a DOM node's `textContent`.
- **FAR:** the numerator masks rows with null/zero `gross_area`, but the denominator keeps their lots. `year_built` separates the two cases:
  - Built-but-unrecorded (WHITE INDUSTRIAL: 50 of 60 rows lacking floor area have a `year_built`) → FAR is understated.
  - Genuinely unbuilt greenfield (GOODRIDGE CORNERS / RIVER'S EDGE / MARQUIS: 0 such rows) → FAR ≈ 0 is honest.
  - S9 (no `fmtFar` floor) STANDS; this is a numerator-coverage question.
- `scripts/check_decisions_log.py` looks for test IDs only in the **decision** column (cell 2), not the pointer column.
- The system `python3` is 3.6 and rejects `http.server --directory`. Use `.venv/bin/python -m http.server PORT --directory ABS_PATH`, run in the background.
- A headless page needs `goto(url, {waitUntil:'networkidle'})` + a short wait. `window.state` is undefined, because `state` is a top-level const.
- `tools/todo_archive.py` only handles `- [x]` items. A `###`-heading TODO item is archived by hand: move the body to `docs/TODO_archive.md` and add a `## Done` line at the top of that list.
- Audit instruments are in the session scratchpad and not committed: `replay.js` (every hood × every view/sub-mode tooltip, zero-token triage), `probe_lt.js`, `probe_nan.js`, `split_measure.py`. Fix #4 would port `replay.js`'s scan into smoke.
