## 3. Technical Learnings

### ⚠️ A principled refusal to draw something must be checked against the affordance it removes
#219 refused `autoHighlight` for a correct reason and silently deleted hover
confirmation. Both halves of this session — a teaser that kept promising, and a
glow that stopped confirming — were caught **by Peter using the map**, not by a
suite that covers both surfaces in detail.

### ⚠️ "Fix half of it" is how a promise outlives its subject
2026-08-01 correctly diagnosed the sparkline/panel mismatch and changed the
**words** while leaving the **picture**. Pictures are louder than captions.

### ⚠️ At pitch, an unpickable prism is a HOLE, not a gap
It does not fall through to its own hood; it falls through to whatever is behind
it. Any picking assertion written at pitch 0 is blind to this — geometry that
overlaps in screen space only overlaps when the camera is tilted.

### deck.gl specifics, all measured in-page
- **An alpha-0 fill still picks** (`metric-extrusion` returns UNIVERSITY OF
  ALBERTA at pitch 0 while painting it `[0,0,0,0]`). Same idiom as
  `hoodHoverLayer`.
- **A highlight makes an alpha-0 layer visible**: deck blends
  `highlightAlpha + color.a * (1 - highlightAlpha)`, so an invisible pick target
  renders as a translucent prism while hovered. That is the Lab's whole glow.
- **A transparent fill still WRITES DEPTH** and hides geometry behind it (499 px
  of the band's own back edges). `parameters: { depthMask: false }` fixes it;
  keep `depthTest` on.
- `overlay._deck.props.layers` + `layer.clone({...})` is the cheap way to change
  one prop without a rebuild. App code already used `overlay._deck` (label
  anchors), so this is not a new intrusion.
- ⚠️ **Screenshot diffs need a NOISE FLOOR.** A no-op `clone()`+`setProps`
  rebuild of an identical frame moves **45 px** on this box. Both accepted
  changes (21, 24) are below it; the rejected ones (499, 818) are far above and
  formed contiguous line segments, not scattered singletons.
