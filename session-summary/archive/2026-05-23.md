## 3. Technical Learnings

- **Claude Code shell quirks:** Claude Code's bash shell doesn't load conda shell hooks — always prefix conda commands with `source /home/peter/miniconda3/etc/profile.d/conda.sh && conda activate edmonton-tax &&`. User's own terminal only needs `conda activate edmonton-tax`.
- **CSV columns confirmed:** `Neighbourhood` (not `neighbourhood_name`), `Assessed Value` (not `assessed_value`), `Assessment Class 1` (tax-class proxy). Always load with `low_memory=False` — `Suite` column has mixed types.
- **No explicit tax-exempt flag** in the assessment CSV. Proxy: `Assessment Class 1 == 'NONRES MUNICIPAL/RES EDUCATION'` (3 rows only).
- **`\n` in NotebookEdit:** Passing `\n` as escape sequence in `new_source` stores literal backslash-n in the notebook. Use actual newlines in the string instead.
- **nbstripout** installed as git filter (`nbstripout --install` from within the repo). Strips cell output automatically on `git add`. Notebooks are now tracked in git.
- **pytest not in original requirements** — added this session, frozen into `requirements.txt`.
