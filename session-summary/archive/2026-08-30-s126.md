#### B. "Mobile fast, desktop slow" is a GPU question (#282)

**The page has no device-dependent load path.** Same 10 requests, same 3.56 MB;
emulated mobile was marginally *slower* (5,841 vs 5,722 ms, median of 5). The
three `matchMedia` calls gate chrome only.

⚠️ **And it is not network-bound at all — every byte lands by ~600 ms.** The
remaining 5–9 s is GPU work: a CDP profile puts **94.6% of samples in
`(program)`** (native/GL), and the top real JS frame is deck.gl's
`_getLinkStatus` — **shader program linking**. Application code does not appear.

**So a "slow load" report is a driver question first:** `chrome://gpu` →
WebGL/WebGL2 *Hardware accelerated* vs *Software only*.

⚠️ **Two limits, both load-bearing and both written into the doc:** this box has
**no GPU** (`ANGLE (… SwiftShader driver)`), so 5.7 s is a software-GL figure,
valid for A/B only; and **emulation shares the host GPU**, so the test can prove
there is no code branch and **nothing** about hardware.

## 3. Technical Learnings

### A stale example is worse than a stale number
The roll-dropout item carried three named parcels for three weeks. All three
were on the roll the whole time. **The count was reported as provisional; the
examples were not, and they were the part someone would have quoted.** A report
sent on the August figures would have named them.

### Audit the actual numerator, never a proxy for it
A parcel-level cross-tab on `Property_Info.zoning` put **$36.8B** in the
unmatched zoning bucket. Wrong — the metric reads `zoning.geojson`, a different
code vocabulary, and the served columns say **zero**. The proxy was more
convenient and more available, which is exactly why it got reached for. This is
recorded in `DATA_INTEGRITY.md` T8 as a method lesson.

### An identifier may acquit even where it must never match
Asymmetry, not exception: matching on a churning identifier creates false
negatives; acquitting with one can only remove false positives. That is what
made it legal to use `account_number` under a decision that says never to match
on it.

### The defect class has a mirror shape
2026-08-18 was *two strings for one thing*. `COMMERCIAL_CLASSES` is the reverse —
*one parcel in two classes at once* — so an enumeration that partitions the
STRINGS still cannot partition the THINGS. Same shape as `rev_frac_exempt`
(2026-08-29). **Ask both questions.**

### A measurement can be right and its framing still misleading
Boot is ~600 ms of network and seconds of shader link. Every prior perf doc here
splits *frames* from *bytes*; neither budget contains the thing that actually
makes the page feel slow to arrive. It needed a third section, not a footnote.
