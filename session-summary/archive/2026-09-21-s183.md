## 3. Technical Learnings

- ⚠️ **A CORRECTION IS AN ASSERTION AND GOES STALE LIKE ANY OTHER — mine lasted
  one day.** Pass 7 tested the host and called A4's blocker falsified; the
  document 403s. `CLAUDE.md` already carries *"test the exact host, not the
  domain"* from two 2026-08-13 instances — this is the same error one level
  further down: **when a blocker says "can't fetch X", the check is fetching
  X.** ⚠️ **Nothing re-checks `STALENESS_LEDGER.md`**, so a wrong verdict there
  has no detector.
- ⚠️ **A DEFERRED ITEM'S JUSTIFICATION ROTS FASTER THAN ITS CLAIM.** Both pass-8
  corrections, and row 25, were items nobody was about to act on where the
  rotted part was the sentence saying *why* it mattered or *what* stopped it.
  **A deferred item is read for its blocker, so a stale blocker is the expensive
  half.**
- ⚠️ **FIXING AN INSTRUMENT CREATES A DISCONTINUITY WORSE THAN THE BIAS.** The
  Bash matcher fixes the undercount going forward and thereby makes the table's
  own history incomparable. **The fix is only half-done until the report refuses
  to let the two regimes be compared silently.**
- **AN UNDERCOUNT WITH A KNOWN SIGN IS NOT USELESS.** The retrieval log could
  only ever produce false zeros, never false reads — so the *used* half was
  always trustworthy and only the *never-opened* half needed the caveat. Worth
  decomposing before calling a measurement "bad".
- ⚠️ **EDITING A TOOL'S OUTPUT BREAKS EVERY DOC THAT INDEXES IT BY POSITION.**
  Three added lines invalidated `sed -n 4p` in two docs. **Grep the repo for the
  command form after changing what a tool prints** — same family as
  `reverify-after-the-last-edit`.
- **A `|` INSIDE A MARKDOWN TABLE CELL SPLITS THE ROW.** `check_decisions_log.py`
  reads the second column; writing `` `Read|Grep|Glob` `` in prose pushed the
  cited test name into a later column and the guard failed with *"names no
  test"* while the name was plainly on the line. Write `` `Read` / `Grep` ``.
- **THE `pre-push` HOOK EARNED ITS KEEP.** Peter merged #516 mid-commit; the
  hook refused the push and named the cherry-pick. **First time it caught this
  for me rather than me catching it** — 9 prior strandings.
