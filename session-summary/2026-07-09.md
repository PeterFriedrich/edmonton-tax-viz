## 4. Technical Learnings
- **Real numbers match the Session-25/26 findings EXACTLY** (served GeoJSON):
  U of A **×2.0** ($7.60M→$15.20M/ac, parcel_frac 50%), Rossdale ×2.81, Riverdale
  ×2.45, Virginia Park ×2.50, Westwood ×2.11, McCauley ×1.97, Downtown ×1.61.
- **7 hoods suppressed** in the served file (parcel_frac < 0.15): 6 set-aside
  (Mill Creek Ravine N/S, Mill Woods Golf Course, River Valley Fort Edmonton /
  Rundle / Victoria) + **MAPLE RIDGE (1.6%, NOT set-aside)** — the one that
  proves the guard earns its keep. (The join logs "8" because an 8th no-assessment
  boundary hood is suppressed then dropped by `export_geojson`'s null-value filter.)
- **GOTCHA — geometry env-drift**: running `main.py` on the Oracle box
  regenerates `roads.geojson`/`zoning.geojson`/`neighbourhood_*.geojson` with
  DIFFERENT coordinates than the committed (CI-generated) files — GEOS/GDAL
  version differences drifted 275/406 hood geometries. **Do NOT commit a full
  local regen of the served GeoJSON.** This session: reverted roads/zoning, and
  for the neighbourhood file did a **surgical per-feature text insert** of the 3
  new keys into the committed pretty-printed OGR text (one feature per line;
  insert before ` }, "geometry":`), matching lot values by name from the compact
  working file. Result: additive-only diff, geometry byte-stable. `value_grid.json`
  happened to regenerate byte-identical (already had lot cols from PR #12).
- **The OGR/geopandas GeoJSON format** is pretty-printed: header on separate
  lines, then one Feature per line with `", "`/`": "` spacing. A plain
  `json.dump(..., separators=(",",":"))` reformats the whole file — don't.
- `scipy`/`sklearn` still NOT in `.venv`. Node 20 + Playwright Chromium ARE
  installed locally (verify scripts run headless with swiftshader flags;
  dispatch clicks via `page.$eval(sel, b=>b.click())` — swiftshader hangs
  `page.click`).
- Pipeline run time ~1m55s on the full roll (439,635 accounts).
