## 3. Technical Learnings
- **PR #39 merged with only NEW-1, not T3c** — the recurrence of the Session-38
  stranded-commit trap. Root cause: I trusted "PR OPEN" and stacked a second,
  distinct commit on an open PR's branch that Peter then merged before the second
  commit landed. Fix pattern now in memory: for a *distinct* concern, branch
  fresh off `origin/master` rather than stacking on an open PR's branch.
- **Money-path unmatched baseline (verified live 2026-07-12):** assessment→boundary
  = `{OLIVER}`, boundary→assessment = `{LEWIS FARMS}`. **SPUR LINES is correctly
  ABSENT** — the `load_assessment` zero-value filter drops it ($0) before the
  join, so it never reaches the money-path warning (DATA.md line ~163-164 frames
  both at the *stormwater* join; only OLIVER survives to the money path).
- **`load_boundaries` expects a `name` property** (uppercased → `neighbourhood_name`);
  `load_assessment` needs the full column set (Account Number, Neighbourhood,
  Assessed Value, Tax Class, Assessment Class 1/2/3, Assessment Class % 1/2/3,
  Latitude, Longitude) — the test fixtures in `tests/test_check_unmatched_names.py`
  build minimal-but-complete versions.
- **maplibre v4 worker is bundled inline** — a single `maplibre-gl.js` is
  self-contained (no separate worker file to vendor). Basemap `sources: {}` means
  no tile server either → truly zero runtime deps after vendoring.
- **Oracle box reaches unpkg + jsdelivr** (both HTTP 200; used for download +
  cross-verification). `data.edmonton.ca` reachable; `edmonton.ca` proper still
  isn't (unchanged).
- **Environment gotchas hit this session:** (1) foreground `sleep` is BLOCKED
  (exit 144) — use `until`-loop polling or background tasks, never bare `sleep`.
  (2) `python3 -m http.server --directory` is NOT supported by this Python — use
  `bash -c 'cd <dir> && exec python3 -m http.server <port>'` as a background task.
  (3) Bash tool CWD PERSISTS across calls — a stray `cd web/vendor` earlier made
  later relative `ls tools/...` fail; use absolute paths or re-`cd`.
- The verify script is Playwright (repo-local `node_modules`) under swiftshader;
  it takes ~10-30s, so run it as a background task and read the output file.
