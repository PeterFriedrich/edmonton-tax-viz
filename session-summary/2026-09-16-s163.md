## 7a. Rec P2 is CLOSED — all three variants DECIDED-NO (PR #434)

Peter asked what the pilot actually *was*, and on hearing it answered the
question §5 left open — **with a better reason than either the project or Opus 5
had reached for.** Not "the design fails" (it doesn't; §3c's redesign is sound).
**The project is the wrong SIZE for it:**

- **It needs an n this project must MANUFACTURE**, not collect as exhaust. A team
  running agent tasks in volume gets the sample for free; one session at a time
  has to buy every run.
- **It needs a reader who does not already know the code.** Sessions here open
  `CLAUDE.md` and the latest handoff as a matter of course — **the routing is
  observably working every session**, which is what the runs would have bought.
- **It needs a still target.** `web/index.html` and `TODO.md` move weekly.

⚠️ **The decisive objection is RECURRING cost.** An ablation result is a snapshot
of *(this model, this doc, this task)*, so it decays as models turn over and docs
change; staying meaningful means re-running it for ever. **A maintenance burden
emitting a number with no reader is this project's own documented standing
failure mode** — the `_classify` warning that logged ~70 days into a channel
nobody read. Building a fresh instance on purpose would be perverse.

**And the substitute is already built.** `verify-temporal.js` *measures* both
invariants (§3a proves each goes red), so they cannot silently break whether or
not a doc mentions them. At 43 verify scripts / 1,174 checks **the guards are the
control and the docs are cheap redundancy above them** — `CLAUDE.md`'s own *test
first, prose second* rule, applied to the question of whether the prose works.

**Revisit if** this becomes multi-person or runs agents in volume — the same
point at which the docs start being load-bearing for a reader other than the
model that wrote them.

Recorded in four places: `DISPOSITIONS.md` §P2 §4, the P2 table row (**ALL THREE
DECIDED-NO**), a closing `DECISIONS.md` row with the prior same-day row marked
