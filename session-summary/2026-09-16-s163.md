- ⚠️ **Hand a self-audit to a different model.** Three errors, one page, none
  caught by any guard or by the author re-reading, all three caught by Fable in
  one pass. The COI warning in the ledger was accurate *and* inert.
- ⚠️ **`check_doc_citations.py` bans citing `CLAUDE.md` by line number** (it
  drifts silently as the file grows). Caught six of mine mid-correction — cite
  the section, e.g. "`CLAUDE.md`'s Key Files entry for X".
- ⚠️ **`scripts/handoff_gap.py` is silent on a docs-only session by design**
  (`docs/` is excluded, or it fires after every commit). **This session landed 3
  PRs and it said nothing.** The exclusion that stops it nagging also blinds it
  to sessions like this one. Not a bug; know it.
- **A correction can revive what it corrects.** Fable's finding killed #431's
  stated reason *and* produced the first ablation design here with a real arm B.
- **`pgrep -f` matched its own shell again** (`pgrep/pkill match themselves`);
  used `ss -lptn 'sport = :PORT'` to get the real server PID instead.
- `.venv/bin/python` is required for the http server — a bare `.venv/bin/python`
  relative to `web/` is `exit 127`, and the failure is silent enough to leave you
  measuring nothing (`confirm-the-server-you-measure`).
- **TODO staleness fixes should SHRINK the file.** The first pass grew it 1.75 KB
  on the file that is 89% of the loaded path; the trim in #432 put it 1.5 KB
  *below* the starting point. Pointer kept, narration dropped.
