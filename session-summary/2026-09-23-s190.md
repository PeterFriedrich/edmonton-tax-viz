## 3. Technical Learnings
- **The new surface check's first run flagged 21 Development hoods as `0.00 new homes / acre`.**
  - That reading was decided on 2026-09-20: `fmtDev` names its integer count on the next line instead of flooring.
  - I checked `DECISIONS`/`COPY_DECISIONS` **before** changing anything, and exempted the unit rather than "fixing" it. This is the S9 failure mode avoided.
  - Any future zero-token check must carry these exemptions.
- **`const state` is not on `window`.** A Playwright `waitForFunction(() => window.state…)` times out. Use `typeof state !== 'undefined' && state.data`.
- **`$` inside an unquoted bash heredoc** caused a "bad substitution" and silently skipped a Python mutation script. Write such scripts through `<<'EOF'` to a file.
- **Falsification harness pattern that worked:**
  - Build the site to scratch dirs (`scripts/build_site.py --src <web> --out <dir>`).
  - For each mutation, copy the dir and `str.replace` in both `index.html` and `dev-build-full/index.html`.
  - Serve each on its own port with the venv `http.server`.
  - **Confirm each server by `curl | grep`** for the mutant string.
  - Run the smoke test on each port alone, one after another.
  - Kill the servers by pid via `ps | awk`, not `pkill -f`.
- **Notebook harness:** exec the jupytext `.py` with `raw = pd.DataFrame(soda(...))` replaced by a pickle load and `display` stubbed. This reproduces every output without re-fetching.
- **`check_doc_citations.py` rejects `§4b`-style citations** when the doc has no such heading. It caught one in my `verify-smoke.js` comment, which was the pytest failure.
