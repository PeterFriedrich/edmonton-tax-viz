## 3. Technical Learnings
- **The digest's branch check reads this session's own TODO text.**
  `vintage_report.check_todo_branch_refs()` flags any backticked branch name in an
  OPEN `TODO.md` item that is not on origin. After the prune it flagged three names
  the branch-review bullet itself had written. Run it after any prune and after
  writing a branch name into `TODO.md`:
  `.venv/bin/python -c "import sys; sys.path.insert(0,'scripts'); import vintage_report as v; print(v.check_todo_branch_refs())"`
- **`gh pr merge` straight after `gh pr create` fails** with "no checks reported".
