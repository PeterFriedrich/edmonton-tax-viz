## 4. Technical Learnings

**THE KEY DISCOVERY — the `url` column (new since last handoff):**
- `fixa-tstc` has a `url` column whose PATH encodes the official bylaw section per zone:
  `…/part-2-…/residential-zones/…`, `…/industrial-zones/…`,
  `…/open-space-and-urban-services-zones/…`, `…/agricultural-zones/…`, plus
  `…-special-area` groups (griesbach, blatchford, ambleside, river-valley, etc.).
- **Use it as a CROSS-CHECK when building the explicit `code→category` dict, NOT as the
  category itself** — the bylaw groups are mixed. Clearest example: the
  `open-space-and-urban-services-zones` group contains BOTH set-aside `A`/`NA`/`PS`/`PSN`
  AND developed infrastructure `PU` (Public Utility) / `UF` (Urban Facilities) /
  `UI` (Urban Institution) / `AJ` (Alternative Jurisdiction). So categorize at the code
  level (as the handoff always said); `url` just catches dict errors.
- The `url` correctly resolves the handoff's `A*`-prefix trap: `AED`→`downtown-special-area`,
  `ALA`/`AUVC`→`ambleside-special-area` (NOT river valley). Good independent confirmation.

**Direct Control zones (`DC`/`DC1`/`DC2`) — ~1,081 rows:**
- These + named special-area zones have NO standard `/part-N/` section in `url`
  (`DC`, `DC1`, `DC2`, plus Blatchford, Century Park, River Crossing, `NSRVES`, `A7`
  Hawrelak, Riverview TC, etc.).
- **Rule decided:** `DC`/`DC1`/`DC2` default to **developed** (stay on scale) —
  conservative, won't wrongly hide land. Named-natural codes (`NSRVES`, `A7`) get caught
  by their OWN explicit dict entry, not the DC default.
