## 3. Technical Learnings
- **deck.gl applies a new `layers` prop on its own frame cadence — erratic
  under swiftshader.** A fixed sleep after `overlay.setProps` raced reading
  `layer.props` (saw the OLD `elevationScale` once at 1.5s, the new one the
  next run). Accessor-based checks DON'T catch this: `getFillColor`/`ratioOf`
  closures read live state, so even a stale layer instance "behaves new" when
  called manually — only static props (like `elevationScale`) distinguish old
  vs new. Fix pattern (in verify-ratio-denom.js): `page.waitForFunction` until
  the layer's static prop converges — the poll doubles as an assertion the
  swap lands.
- **The Money-flow honesty rule is load-bearing for design questions**, not
  just display copy: it fully determined the "total services" answer before
  any new judgment was needed. Check SPEC_utilities' locked sections before
  treating a deferred decision as open.
- `#denom`'s CSS is default-hidden (`#denom-hd, #denom { display:none }`) —
  the load-handler juggling the Session-27 notes mention was only ever needed
  for `prism-hd`/`prism-row`. New layers-panel sections should copy the
  `#denom` pattern.
- Skew-table convention (FINDINGS §6.x): skews are computed UNCLAMPED on the
  raw set (my first pass clamped to p2.5–p97.5 first — recomputed to match).
- `node -e` can't `require('playwright')` from the repo root — write debug
  scripts into `tools/profiling/` so they resolve its `node_modules`.
- PR #33 merge was clean: `git diff feature/ratio-denominator-picker master`
  empty (no Session-31/32-style stragglers; branch was single-commit
  `10f0d58`, merged as `e0da845`).
