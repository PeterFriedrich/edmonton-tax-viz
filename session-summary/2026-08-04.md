## 3. Technical Learnings

**⚠️ `--geojson-out /tmp/x.geojson` DOES NOT MAKE A LOCAL `main.py` RUN SAFE —
and `TODO.md`'s DATA VINTAGE item says it does.** The flag redirects only the
main GeoJSON. A full run still wrote **`roads.geojson`, `zoning.geojson`,
`value_grid.json`, `dev_grid.json`, `temporal.json`** into `web/data/` from
**2026-07-06** raw data — the exact rollback that item exists to prevent. Caught
by `git status` immediately after, restored with `git checkout -- web/data/`,
**nothing committed**. The real mitigation is that restore command. Open item.

**⚠️ THE `#about` POD WAS ALREADY ~112px FROM OVERFLOWING THE TOP OF THE SCREEN
at 720px tall, BEFORE this session's change** — it is anchored `bottom` and
grows **upward**, so extra content runs off the top **with no scrollbar to
notice**. Now capped: `max-height: calc(100vh - 110px)` + `overflow-y: auto` +
**`box-sizing: border-box`** (max-height is content-box by default — the
`#temporal` lesson). **The latent pre-existing overflow is the more useful find
than the bug I introduced.**

**⚠️ `.revrow` IS "SWATCH + LABEL + VALUE", NOT "BAR + LABEL + VALUE".**
Repurposing its 9px `i` as a proportional bar squeezed the label column, wrapped
every row, and took the section to **348px**, pushing the whole pod off-screen
at every height 900→720. Dropped the bar; four percentages carry it.

**⚠️ THE "ALL ZEROS" MOBILE PROBE WAS THE PROBE'S OWN FAULT.** `#optpanel`
carries `.folded` by default at ≤640px, so its rows have **no layout box**.
Remove the class first. Re-measured at 390/360/320 with all 10 rows visible:
**no clip, no overflow, 178–235px clearance to `#botleft`.** (The TODO item had
recorded this cause for the S74 left-edge work — it just was not applied here.)

**⚠️ PLAYWRIGHT RESOLVES FROM `tools/profiling/node_modules`, NOT THE REPO ROOT.**
There is no root `node_modules`. A scratch script in `/tmp` needs
`NODE_PATH=/home/opc/edmonton-tax-viz/tools/profiling/node_modules`.

**⚠️ DO NOT COMMIT A HAND-RUN `generate_status.py`.** It stamps `last_checked`
with today's date — a freshness claim for a check that never happened, and the
staleness banner reads that field. Let `refresh.yml` publish it.

**⚠️ DO NOT RE-PIN `expected_columns.json` BEFORE THE COLUMNS SHIP.** Measured:
