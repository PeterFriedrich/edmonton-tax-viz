## 3. Technical Learnings
- **This box over-wraps text.** It has fallback fonts only, so the phone title-vs-`#controls` clearance in verify-search is a **WARN, not a FAIL**.
  - Full-build Lab at 360px reads 3 lines here (bottom 77 vs controls top 58).
  - Development, Ratio and Lab already sat at exactly 58 before this change.
  - **`#controls top: 58px` is a fixed number that a 2-line title meets exactly.** That is pre-existing fragility.
- **A space at the start of a `::after` caret is a line-break opportunity.** Without it, ▾ (UAX14 class AL) glues to the last word.
- **`verify-peek` has a pre-existing flake.** Its card-vs-lens check normalises `<br>` but not `&lt;`, so it fails whenever the tapped hood's readout contains `<` (for example "<$1 to $5,115"). It hit once on the full build, then passed on 2 reruns and on master. **Not fixed.**
- **Every view has a panel** (`hoodPanelLens()` is true for all of them when `hasRoadsLife`), and every hood has a `temporal.json` row. So `searchHood` only applies on a stale or partial deploy.
- **A scratch script outside `tools/profiling/` must `require` Playwright by absolute path:** `/home/opc/edmonton-tax-viz/tools/profiling/node_modules/playwright`.
