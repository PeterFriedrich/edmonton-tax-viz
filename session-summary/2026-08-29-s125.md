## 3. Technical Learnings

### Reproducing before acting found that the backlog was wrong twice
Two of three recorded diagnoses were incorrect, and one item had never been a
defect at all. **A stale diagnosis is worse than no diagnosis: it told us the
revenue-panel failures had one known cause, so nobody looked at the three that
had a different one.**

### The contention artifact cost more than one wrong number
S124's 5.4s timing error and S125's phantom backlog item are the **same root
cause** — measurements taken while other chromiums ran. It didn't just produce a
bad number; **it manufactured a TODO item that sat open for two weeks.**

### Falsify the test against the defect, every time
`verify-loading-overlay.js`'s gate check (S124) and the new epsilon (S125) were
both falsified by reintroducing/injecting the real defect. The S124 one
**passed** against the defect and forced a retraction. Falsification is not
ceremony here; it has caught something on both occasions it was run.

### An absence is argued by trying to disprove it
Run the searches that would FIND the missing thing; show they return nothing;
state the epistemic limit (not-in-catalogue-on-date ≠ does-not-exist).

### Write invariants that fail when the publisher fixes the defect
House style now. A report that keeps agreeing with itself after being acted on
is one nobody notices has succeeded.

### Environment quirks (this box) — all still true
- ⚠️ **Playwright lives in `tools/profiling/node_modules`** — `/tmp` scripts
  cannot `require('playwright')`.
- ⚠️ **Run verify scripts ONE AT A TIME**, and check `ps aux | grep -c
  "[c]hrome"` + `/proc/loadavg` **before trusting any timing**.
- ⚠️ **Three font families, none of the CSS stack** — never size CSS from a
  headless text measurement here.
- ⚠️ **`pkill` in a `&&` chain returns 144 and aborts the chain** — it silently
  skipped a commit this session. Run it in its own call.
- ⚠️ System `python` is 3.6.8 — use `.venv/bin/python`. HTTPS needs `certifi`.
