## 3. Technical Learnings
- **Serve the site with `.venv/bin/python -m http.server`, never the system `python3`.**
  - The system one is 3.6.8, whose `http.server` is single-threaded.
  - It wedged on Chromium's keep-alive connections: curl returned 000 and Chromium `ERR_EMPTY_RESPONSE`.
  - This is recorded in memory `oracle-server-headless-verify`.
- **Grid pages are slow to tear down under software GL.**
  - Tearing down a page that drew a grid takes 10–25 s (freeing GPU buffers). Frames themselves are fast (31–125 ms for two).
  - `page.close()`, reload and navigating away all pay it, and `browser.newPage` hung behind it.
  - Fix: `chromium.launchServer()` per load, then `server.kill()` the last one (about 0.2 s).
  - Playwright's real `page.click` also waits about 4 s for stability on the grid, so use a JS `.click()`.
  - Use `waitForFunction(..., {polling: 100})`. The default polls on `requestAnimationFrame`, which is starved here.
- **Scratch-site layout:** `scripts/build_site.py --src web --out <dir>` puts the full build at **`dev-build-full/`**, not `full/`.
- **The 50 m grid button's text changes after idle** (it gains "· 7.6 MB"). Identify controls by `data-*` attributes, not text.
- **`pkill -f` kills its own shell** (exit 144). Kill by pid taken from `ss -ltnp` instead.
- **No leftover processes** from this session: the test server on 8956 was killed, and no headless_shell remains.
- **Latent pre-existing issue, noticed but not fixed:**
  - On a data file too old to carry the "Since 2009" columns, the long-window button is hidden.
  - But `state.devWindow` defaults to `"long"`, a value no button offers.
  - The old comment claimed "default is 5yr". The audit brief L6 asks to size or dismiss this.
