## 3. Technical Learnings
- **The simulation harness pattern worked:**
  - Copy the notebook into a scratch dir with symlinked cache dirs.
  - `str.replace` patches on the source; assert each anchor occurs exactly once.
  - Run it through `rc.run_one()` with `rc.STANDALONE`/`rc.REPO` repointed.
  - The harness was `scratchpad/mutate.py`, which is not committed. Its patches are described in findings §3/§4.
- ⚠️ **Mutation loops on `scripts/*.py` need `__pycache__` cleared per mutation**, and `python -B`. The first pass reddened the WRONG tests (the stale-.pyc memory, again).
- ⚠️ **A test that searches a YAML step for `shell: bash` passed while that key was deleted**, because the comment above it also said `shell: bash`. It now matches a line equal to the key.
- **`check_decisions_log.py` reads only the decision column (cell 1)** for test IDs.
  - A test cited only in the last column does not count.
  - A `|` inside inline code splits cells.
  - Its failure was masked once by piping it into `| tail`; check `$?` directly.
- **Local runs without F3 read the download caches:** `exemption_uncertainty` then ran in ~8 s entirely from disk.
- **`gh pr merge` right after `gh pr create` merges before CI registers**, and `gh pr checks` says "no checks reported". Watch the post-merge master run instead. #549's was green.
