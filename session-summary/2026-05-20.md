## 3. Technical Learnings

- CRS for area calculation: **EPSG:3400** (NAD83 / Alberta 10-TM Forest) — equal-area, appropriate for Alberta. Input boundaries are likely WGS84 (EPSG:4326); always reproject explicitly before `area_acres` calculation.
- Neighbourhood name normalization strategy: strip whitespace + uppercase. Fuzzy matching is a known rough edge — a correction dict will live in `join_and_calculate.py` if needed.
- Tax-exempt properties: **flag and include** (do not silently drop). The analysis is assessed value, not tax yield; exclusion is a policy choice left to the user.
- Condo parcels (multiple units, one land record): include as-is — inflated $/acre for high-rises is correct for density analysis.
- Module boundary rule: no analysis logic in `plot_choropleth.py` — rendering only. This is what keeps Phase 2 (Kepler.gl) a drop-in swap.
