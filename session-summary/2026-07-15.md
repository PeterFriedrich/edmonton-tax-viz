## 3. Technical Learnings
- **Fable-appropriateness ranking (reused twice this session):** best fit =
  design already decided + Oracle-doable + tight verify harness + no design
  fork. D5 data layer and the dev grid both qualified; D0–D4 (sidebar UI, no
  pattern yet) and the Infill *score* at fine grain (needs a design call) did
  not.
- **The dev grid reuses the Glass grid's exact binning** (`export_value_grid`'s
  EPSG:3400 floor-bin at 100 m) so a dev-grid cell and a value-grid cell with
  equal SW corners are the SAME square. `export_dev_grid` replicates the
  projection + `//cell_m` binning; it does NOT import from export_value_grid
  (kept independent — permits are a different point set).
- **Permits carry full-precision lat/long**; our slim `$select` just wasn't
  fetching them. The 2026-07-12 choropleth DECISION explicitly retained
  lat/long "for a possible future point/heatmap variant" — this IS that
  variant, no decision reopen needed.
- **Geocode lag is the load-bearing caveat for ANY permit point layer:**
  ~1–2%/yr nulls 2021–2023 but 994 (2024) + 3,564 (2025) — fresh permits await
  geocodes. Disclose from a `coverage` block written into the data file, never
  backfill with hood centroids.
- **FIR format eras:** the debt schedule is `AA(1)-Debt` (2009+),
  `Schedule AA` in per-year files (2004–08), `GR Debt Info` legacy `.xls`
  (2003). Same 8-column header throughout. Municipalities keyed by stable CODE
  (Edmonton 0098 / St. Albert 0292 / Strathcona 0302), name cross-checked.
- **The Development/Infill family docs live in `SPEC_development.md`, not
  ARCHITECTURE.md/UI.md** — a deliberate pattern shift for newer lens work.
  ARCHITECTURE now has the load_permits entry (item E); **UI.md still lacks any
  Development OR Infill section** (pre-existing, family-wide gap — a P2.5
  doc-drift candidate, NOT done this session).
- **Infill at fine grain assessed, NOT built (Peter not yet asked):** the
  z-mismatch SCORE doesn't survive 100 m grain (~88% of inhabited cells have 0
  activity → every quiet cell reads "opportunity"; set-aside + residential
  gates are hood-level constructs). The honest fine-grain version is the
  DECOMPOSED ingredients — a per-cell FAR texture (per-point `gross_area` +
  `_point_lot_stats` dedupe, `build_hood_lot_acres` keyed on cell) UNDER the
  now-shipped permit spikes, verdict staying hood-level. Logged in TODO under
  Lens B. Middle path if a finer score is ever wanted: prototype 250–500 m
  cells first.
