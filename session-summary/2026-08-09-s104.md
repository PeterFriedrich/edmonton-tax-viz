## 3. Technical Learnings

- ⚠️ **THE ONE TO KEEP: a number read off a SHIPPED DISPLAY FILE is not a fact
  about the world.** `neighbourhood_value_per_acre.geojson` is post-setback,
  post-simplify geometry, and `join_and_calculate.py` already documented both
  as DISPLAY-only — the doc that got it wrong never opened the raw file. **The
  tell was free: all 406 hoods shrank**, which no story about *missing land* can
  produce. Any figure describing the city must come from `data/raw/`.
- ⚠️ **The mechanical guard cannot reach this class at all.** Every citation in
  the retracted passage resolved perfectly. The pointer was fine and the number
  behind it was not. Judgement halves do not automate.
- ⚠️ **A guard holding a private copy of the number it guards validates itself,
  not the site.** That is why the fix for the duplicate-figure class is
  **de-duplication, not another checker**.
- ⚠️ **THE DEFECT COUNTS ARE INCREMENTAL AND DO NOT SUM.** 2,322 + 131 =
  **2,453**, but the true cumulative shortfall is **2,448** — 5 of 2024's
  missing accounts returned (`SPEC_temporal.md` §0.1). **My first draft summed
  them.** Both consumers now state a *single* year's count or fall back to
  wording with no number.
- ⚠️ **A rule enforced against one spelling of a mistake is enforced against the
  spelling nobody uses.** The colon form is what the terminal makes clickable,
  so it is the path of least resistance, and the guard read **green** the whole
  time — worse than no guard, because green was taken as evidence.
- ⚠️ **Writing about a banned form trips the guard.** It happened **three
  times** this session (the guard's own docstring, `DECISIONS.md`,
  `ARCHITECTURE.md`). The documented fix works: wrap the form in **double
  quotes** to mark it a mention. Backticks do **not** work — `_is_mention`
  counts `"` only.
- ⚠️ **`audit_roll_continuity.py` CACHES, and a warm cache makes a "re-run" a
  replay.** Default `--cache-dir /tmp/roll_continuity`. The first attempt
  reproduced 1,534 / $1.62B off 45-hour-old files and read as a real null
  result. **Now logs `CACHE HIT` at WARNING with the file's age** — pass a fresh
  `--cache-dir` anyway.
- ⚠️ **That tool fetches from SOCRATA, not `data/raw/`.** A local
  `download_data.py` does **nothing** for it. Learned by doing it (~80 MB).
- **The roll has not moved.** `q7d6-ambg` is byte-identical 2026-08-07 →
  2026-08-09: **439,631** rows, md5 `8bd57af7fe4a63268fe538d91d6b9d5a`. The
  local snapshot was 439,685 (2026-07-06), so the roll *shrank* by 54 accounts
  in that window — real, but irrelevant to that tool.
- **S103's own record was overstated**: it said `FABLE_AUDIT_BRIEF.md` cites
  three missing files. **Two have existed since `a614597` (2026-05-16)** —
  `docs/security-audit.md` and `CONTRIBUTING.md` (repo root). Only
  `docs/SPEC.md` was missing, and it **never existed in history**.
