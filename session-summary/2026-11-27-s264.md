## 3. Technical Learnings
- **Mutation harness gotchas:**
  - `src/load_boundaries.py` has a comment between `to_crs(epsg=3400)` and the area line, so an M11 pattern that assumes the two lines are adjacent silently doesn't apply. Use two separate single-occurrence subs, and assert the count.
  - Restoring each time needs `git checkout`, the pristine roll copied back and `__pycache__` cleared (see the `same-length-sed-leaves-stale-pyc` memory). Assert the restored HEAD.
- **Control residuals:** the roll-year check's control residual is **+1.6%**, not +0.4%. M2 shows +0.4% and M2b +0.6%. The 5% band compares only the residential base, so missing non-residential accounts can't move it. That is the basis for F1.
- **The University of Alberta Farm tooltip's $0 low endpoint is a true computed $0** when its exempt share rounds to 1.0. F3 is therefore a check that can fail a correct page, not a wrong readout. It fired under 2 mutations, not yet on real data.
- `check_revenue_deltas.py` always exits 0 and files an issue only when a hood moves ≥10% **and** ≥$1M. A 10% rate error spreads under that threshold.
- `git switch -c X origin/master` makes X track master. Run `git branch --unset-upstream` and assert the branch name before committing.
