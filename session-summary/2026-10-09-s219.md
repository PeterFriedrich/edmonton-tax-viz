## 3. Technical Learnings
- **Playwright defaults to `colorScheme: 'light'`.** Any page that follows the OS loads light under every verify script. Hence the `navigator.webdriver` → dark rule (same precedent as `maybeAutoGuide`). To test light, store `theme=light`, or unset webdriver via `addInitScript` (as `readerPaths()` and `verify-guide.js` do).
  - ⚠️ Unsetting webdriver also auto-opens the guide card. Seed `localStorage.guideSeen = '1'` in the same init script.
- **Don't use `data-theme` on buttons.** The toggle uses `data-pick`, so no future unscoped `[data-theme=…]` rule can match a button.
- **A CSS comment inside `:root` that names a token (`--accent: dark makes…`) fooled a regex parser.** It swallowed the next declaration. `test_theme_tokens._decls` strips comments first.
- **`build_site.py` rmtree's the output dir.** A running `http.server` then shows `(deleted)` in `/proc/<pid>/cwd`, but it still serves the NEW files, because it captured the directory as a path string at startup. The reader checks passing on new markup proved it.
- **The phone peek card does not open from a synthetic `touchscreen.tap` in headless runs, in dark either.** To render it, call `openPeek(<feature>.properties)` directly. `hoodProps()` returns null for some names.
- **The Read tool's image preview exaggerates faint ghosting.** Measure pixels with Pillow before "fixing" translucency: the peek card's ghost was 3/255.
- **Scratch scripts are in `.../scratchpad/p4/`** (`shots.js`, `grey.js`, `toggle.js`, `mut.sh`, `vt-reader.js`, `contrast.py`). They are not committed.
  - `vt-reader.js` is `verify-theme.js` with `STATES` emptied, so only the reader paths run, in about 2 minutes.
  - `mut.sh` filters FAIL names out with its `sed`, so it prints counts only.
