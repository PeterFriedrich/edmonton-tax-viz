## 4. Technical Learnings (don't re-derive)

- **One lat/long per account is the grid's core hazard**: WEM is $1.285B
  behind a single point; citywide, lots > 1 ha are 5,524 rows carrying
  $43.6B (18% of $237.5B). Any point-binned density map needles them.
- **Condo `lot_size` is unusable as a summed denominator** (DATA.md §2,
  confirmed): at the 3,002 multi-unit points it is variously the parcel
  duplicated per unit / apportioned shares / null (one 1,059-unit tower:
  1,051 nulls; only 17% of multi-unit points share one value). Per-row
  footprint spreading is safe (each row spreads over its OWN square);
  summing lot acres is not. Ground-acre denominator chosen for the grid;
  lot-acre variant is a TODO with a required dedupe heuristic.
- **Assessment roll join to dkk9-cj3x on Account Number: 100% coverage**
  (439,685 both sides); `lot_size` ~0.6% null; lat/long 0 nulls.
  287,163 distinct points; grid-size sweep: 75 m → 52.7k, 100 m → 34.7k,
  125 m → 24.9k, 150 m → 18.9k occupied cells (pre-spreading).
- **`deck.GridCellLayer` IS in the loaded 9.0.38 dist bundle** and works
  under the interleaved overlay; SW-corner positions from EPSG:3400
  binning render fine (~1.2° grid-convergence rotation vs mercator ≈ 2 m
  on 100 m cells — invisible).
- **`pytest.approx` doesn't support `<=`** — use a manual tolerance
  (`x <= bound * (1 + 1e-9)`).
- The `#lens` panel CSS hides `#layers` by default
  (`display:none` in the stylesheet) — probe visibility with
  `getComputedStyle`, not `el.style.display` (first verify-glass run
  false-alarmed on this).
- Labels: 128 px SDF atlas (`fontSettings: {fontSize: 128, radius: 24,
  smoothing: 0.08}`) fixed city-zoom blur; atlas change moves the
  characters sublayer `sizeScale` (1.325 → 1.2625) — verify-labels.js
  catches a stale `LABEL_DRAW_SCALE` if fontSettings change again.
- Deploy reminder unchanged: merge ≠ deploy; `gh workflow run "Refresh map
  data"`, then `git pull --rebase` before pushing (auto-refresh commit).
  The weekly refresh will regenerate `value_grid.json` automatically once
  merged (it rides `main.py`).
