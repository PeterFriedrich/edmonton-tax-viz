### ⚠️ The brief asserted two things that were false — both found by re-checking §3

**1. The verify-script claim was wrong in the direction that mattered.** The
brief, `TODO.md` and `PLAN_frontend_refactor.md` all said the 8 profiling scripts
naming `index.html` name it as a served **URL**, so an ESM split leaves them
working. **Seven do. The eighth does not.**
`tools/profiling/verify-staleness-banner.js:66` does
`fs.readFileSync(… 'web','index.html')` and regexes `const STALE_DAYS = (\d+);`
out of the **source**. That literal is at line 620, under the `tunables` banner,
**inside the `<script>` block a stage-2 split moves.** It fails loudly
(`process.exit(1)`) — but it fails on a *correct* migration.

⚠️ **Note the shape:** this is a third member of the
`check_cost_copy.py` / `check_served_columns.py` family — **a guard asserting on
the TEXT of the artifact rather than on the value.** That is already
`PLAN` §7's second open question; it now has a member on the side the brief had
written off as safe.

**2. The reasoning-narration warning had an invented mechanism.** §4 said
narrating reasoning could *"silently reroute the session to Opus mid-task."*
Read out of the CLI binary: `reasoning_extraction` **is real** — an API refusal
category in `stop_details.category`. But refusal fallbacks are a **per-category
route map**, and for Fable it is `{bio → claude-opus-5, cyber → claude-opus-4-8}`.
`reasoning_extraction` **is not in it**, so an unmapped refusal resolves to
`matched:"none", reason:"unmapped"` and **the request stops.** The catch-all is
off unless `CLAUDE_CODE_REFUSAL_FALLBACK_CATCH_ALL` is set, and it is not set
here. **The advice stands; the penalty is a hard stop, not a quiet downgrade.**

### ✅ Why inlining beat instructing — the generalizable move

I first proposed adding a *gate* to §2 ("no split verdict without answering
whether `state` decomposes"). **That was a bad proposal and I withdrew it:** you
cannot characterize 110 call sites from one symbol's range, so the gate would
have pushed Fable into a full read of `web/index.html` — **~429 KB ≈ 107K tokens,
~$1.07 at the Fable input rate, recurring on every context re-read.** Measuring
it here and inlining the answer cost **3.3 KB once**. Same move that took the
reading list 733 KB → 149 KB in S137. **When a brief needs a fact the index
cannot supply, measure it in the cheap session and inline the result — do not
instruct the expensive session to go look.**

### ✅ CODEMAP's actual limits (I overstated these mid-session and corrected)

CODEMAP is right for **navigation** and for **what is central** — its own header
says *"use it for what is central and would this seam hold, never as ground truth
for a final module boundary."* It correctly flagged `state`. What it **cannot**
do is answer whether `state` decomposes — **a reference count cannot separate
reads from writes, however accurate it is.** That is a category limit, not a
precision problem. Also noted: **CODEMAP lists 18 sections against 19 banners** —
the `base map` banner (line 2019, ~15 lines) has no indexed symbols and is
dropped, so its section list is not a complete banner inventory. Harmless here.

### ✅ Plan mode is the WRONG tool for this brief — three concrete conflicts

Peter asked whether to use plan mode (relayed advice said you'd have to "cut it"
after the plan so it doesn't implement). Findings from the binary:

- ⚠️ **Plan mode is the most agent-hungry mode there is.** Its Phase 1 says
  *"Launch up to N agents IN PARALLEL … to efficiently explore the codebase"*;
  Phase 2 launches more. A no-agent variant (*"Read and explore the relevant
  files directly"*) exists, gated on `o = fY() && mx()==="default"`.
- The "cut it" advice is **right in shape, wrong in mechanism.** Plan mode does
  not run off and implement — the model **must** end its turn with
  `AskUserQuestion` or `ExitPlanMode`, and `ExitPlanMode` is an approval dialog.
  **You just decline.** No interrupting.
- ⚠️ **But it fights this brief in three places:** it instructs *"Include only
  your recommended approach, not all alternatives"* (the brief demands verdict +
  counter-argument + alternative + falsifying evidence, ×7 levels); its
  deliverable is an *implementation* plan ("name the critical files to be
  modified") when the likely right answer is **change nothing**; and it forbids
  ending a turn any way but `ExitPlanMode` while brief §5 says end with
  `/handoff`.

**Decision: do not use plan mode.** Use `--disallowed-tools` + (if ever wanted)
path-scoped `permissions.deny`. Rule syntax is `"Edit(//etc/*)"` — the `//`
prefix is absolute-path. ⚠️ **I never tested whether `**` recurses or only `*`
works — test before trusting a deny glob.**

### ✅ Subagent env vars — only one of them is a cap

Verified against the CLI binary, 2.1.258:
- **`CLAUDE_CODE_SUBAGENT_MODEL` only sets a DEFAULT.** An agent definition's
  `model:` and an explicit per-spawn `model` both override it. Changelog string:
  *"Changed `CLAUDE_CODE_SUBAGENT_MODEL` to set the default subagent model rather
  than override everything."*
- **`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` is the cap** — it removes the `model`
  parameter from the Agent tool's schema outright (`n.omit({model:!0})`) and
  ignores agent-definition models.
- ⚠️ **Still nothing pinned by default**: no `.claude/agents/`, no
  `~/.claude/agents/`, both vars unset in the shell.
