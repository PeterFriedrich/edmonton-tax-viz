⚠️ **Stock read as flow.** The 9 hits were a one-time backlog a single prune had
exposed, not a recurring signal. A level was measured and reported as a rate.

### 2b. `handoff_gap.py` — measurement right, both channels dead

Verbatim from the hooks reference: *"SessionEnd hooks have no decision control…
Claude Code discards their JSON output fields, such as `systemMessage`."* Its

piping stderr to `/dev/null`.** This applies on `/clear`, the exact moment
`CLAUDE.md` names.

⚠️ **18 tests pinned the JSON *shape* and none asked whether anything reads it.**
`check-where-the-value-can-be-wrong` at the channel level.

## 3. The fixes (PR #438, Opus 5)

### 3a. ⚠️ PreCompact resolved the OPPOSITE way from what the audit proposed

The audit said "verify PreCompact empirically; if `additionalContext` is not
honoured, use the manual-`/compact` stderr route." **That route does not
exist** — it requires exit 2. From the reference:

- PreCompact discards `systemMessage`/`continue`, is **not** one of the events
  that read `hookSpecificOutput.additionalContext` (it sits in the top-level
  `decision` group; the doc names Stop/SubagentStop as that row's exceptions),
  and exit-0 stdout goes to the debug log.
- **Its only surface is exit 2 = block compaction** — and *"If compaction was
  triggered to recover from a context-limit error… the current request fails."*
  A script whose contract is *it can never end a session badly* may not use it.

**So the PreCompact hook was DELETED, not rewired**, and the signal moved to
**`SessionStart`** — which fires `source: "compact"` after a compaction and
`"clear"` after `/clear` (the two moments `CLAUDE.md` names), reaches Claude via
`additionalContext`, and lands while the reader still has context to act on.
`SessionEnd` now writes to **stderr** with `2>/dev/null` dropped from that hook.

**No `/compact` experiment was needed.** Settled from the reference.

### 3b. The mutation that caught my own test

8 mutations red-then-green. **M5 stayed green when it should have gone red:**
`test_session_start_message_does_not_claim_the_same_session` asserted on
`message(g, at_start=True)` — the helper — so flipping `main()`'s call site back
to the end-of-session wording was invisible to it. ⚠️ **`check-where-the-value-
can-be-wrong`, written *inside the fix for that exact class*.** Fixed to assert
on what `main(["--session-start"])` actually emits. Also M7's probe was broken
(no source match) and had to be redone — a failed mutation is not a passing
guard.

### 3c. Clamp-drift dedup

`refresh.yml` skips `gh issue create` while a `clamp-drift` issue is open.
**The revenue-delta step stays undeduped on purpose:** a delta is a transient
*event* (each firing is its own fact); drift is a persistent *state* that
recurs every Monday until the literal is re-decided. `RUNBOOK.md` §0c notes the
consequence: closing without moving the clamp re-arms it.

## 4. Technical Learnings

- ⚠️ **The project's guard discipline answers one question of three.** It
  falsifies well — "does it fire on a defect". Both failures found today pass
  that test perfectly. The unasked ones: **can the defect occur here?** and
  **does anyone see it fire?** That is the next audit (§5.3).
- ⚠️ **Thoroughness at the wrong altitude reads as rigour.** The 18 shape tests
  were not lazy; they were well-formed, numerous, and blind to the only thing
  that mattered.
- **Hook channels are per-event and mostly discard.** Never assume an event
  reads JSON. `SessionEnd`, `PreCompact`, `PostCompact`, `Setup`, `Notification`
  and others discard `systemMessage`; `additionalContext` is honoured on
  `SessionStart`, `UserPromptSubmit`, `PostToolUse`, `Stop`, `SubagentStart`,
  `PostModelSwitch`. Reference: `https://code.claude.com/docs/en/hooks.md`
  (fetch with `curl --cacert $(.venv/bin/python -m certifi)` — the box's CA
  bundle is stale; the `docs.anthropic.com` URL 301s to `code.claude.com`).
- **A one-off cleanup creates a stock of hits that looks like a live signal.**
  Before building a detector, ask what produces its input *on a schedule*.
- Inherited wiring is unexamined wiring: the dead SessionEnd channel came from
  the pre-existing echo hook and was never questioned because it was already
  there.
