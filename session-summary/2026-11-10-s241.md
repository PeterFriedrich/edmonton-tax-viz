## 3. Technical Learnings
- **verify-theme needs a BUILT site:**
  - Build with `.venv/bin/python scripts/build_site.py --out <scratch>/site`.
  - Serve with `.venv/bin/python -m http.server 8731 --directory <site>`.
  - Run with `NODE_PATH=tools/profiling/node_modules node tools/profiling/verify.js http://localhost:8731/ theme`.
  - A run takes ~495 s, so run it alone.
  - The runner prints one summary line ("114 checks — all green"). Grepping for `PASS` finds nothing; that is its format, not a failure.
- **`pkill -f "http.server 8731"` kills its own shell (exit 144)**, and the rest of a `&&` chain silently doesn't run.
  - Use `pkill -f '[h]ttp.server 8731'` in its own Bash call, or a pidfile.
  - It bit twice this session.
- **`gh pr checks --watch` can exit before checks register** on a fresh PR. The merge then says BLOCKED, so wait again before merging.
- **Levy vs FIR has mostly been explained since 2026-08-25.**
  - The premises behind it (A1/A2) are ACCEPTED and sized weekly by `notebooks/verified/03_assumptions.py`.
  - Early this session I called it an "open discrepancy". That overstated it.
