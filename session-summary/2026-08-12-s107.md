## 3. Technical Learnings

### ⚠️ MY VERIFY-SWEEP HARNESS PRODUCED THREE WRONG ANSWERS IN ONE DAY
Every one read as a credible result. **The scripts were fine each time.**

1. A grep pattern matching neither crash signature → **~31 scripts that had
   crashed on a missing URL argument were reported as PASSING.**
2. A `grep -c green` tail that **discarded every RED line** it existed to show.
3. A URL fallback keyed on `expected string, got undefined`, which misses
   `verify-smoke.js`'s `usage:` message → that script ran without its URL and
   scored **RED with an empty reason**.

⚠️ **NEARLY EVERY VERIFY SCRIPT REQUIRES A BARE URL ARGUMENT.**
`verify-deviation.js` is the exception — it defaults its own.
Working sweep idiom (writes per-script lines to a file; ~25 min for 33 scripts):
```bash
cd tools/profiling && : > /tmp/sweep.txt
for f in verify-*.js; do
  out=$(timeout 200 node "$f" 2>&1); rc=$?
  if echo "$out" | grep -qE "expected string, got undefined|^usage:"; then
    out=$(timeout 200 node "$f" http://localhost:8777/index.html 2>&1); rc=$?
  fi
  nf=$(echo "$out" | grep -icE "^FAIL|CHECK\(S\) FAILED|FAILURE\(S\)")
  [ "$rc" -ne 0 ] || [ "$nf" -gt 0 ] && echo "RED $f" >> /tmp/sweep.txt || echo "green $f" >> /tmp/sweep.txt
done; echo DONE >> /tmp/sweep.txt
```
**Correct sweep result this session: 31 green, 2 red** (the two above).

### ⚠️ `verify-peek.js` IS FLAKY UNDER PARALLEL LOAD — NOT A REGRESSION
Red in the sweep; re-run under CPU contention it failed **differently**
(`peek=null` vs `peek=HAZELDEAN`); run **3× on an idle box it passes 3/3 with
zero failures**. Two distinct failure modes under load, none without it.
Cost ~an hour (worktree at the pre-change commit + a second server on :8778)
before the load hypothesis was confirmed. **Re-run it alone before acting.**

### ⚠️ `exempt` IS NOT ALWAYS THE LOWER END OF THE BAND
A first verify check asserted `exempt ≤ levied` and **was wrong — the code was
right.** Removing institutional revenue drops the citywide average by
**$1,303/acre**, so a hood losing less than that in absolute dollars *gains*
ground: **EVERGREEN +$87** (loses $1,215), **RIVER VALLEY CAMERON +$842** (loses
$461). Both near-floor hoods with a high institutional *share* but few dollars
behind it. Fields are named `levied`/`exempt`, never hi/lo; `deviationBandSpan`
sorts for display. The true invariant is on the **rate**, not the deviation.

### ⚠️ THE BAND COLOUR IS A RULE, NOT A TASTE
Only an **achromatic** mark cannot imply a pole. Blue was rejected on *meaning*
as much as numbers — it is cool, and the surplus pole is teal.
`verify-deviation.js` pins **`R === G === B`**, not a hex.

```bash
  --mode dark --surface "#0a0a0f" --pairs all
```

### The exemption question, sized
The **$396.9M** gap between our modelled $2,714,729,507 and the City's budgeted
$2,317,789,000 **cannot be split**:
- **Uniform rescale changes NOTHING** — 0 hoods reclassified. Every hood *and*
  the average scale by the same 0.854. Any midpoint total is also a no-op.
- **Swapping only the average's numerator** moves 44 hoods — and is incoherent
  (hood values from our model, benchmark from the City's budget).
- **Only the locatable part works**: removing institutional revenue reclassifies
  23 hoods, but covers **$131M of $396.9M** — about a third.

⚠️ **The direction of the error is UNKNOWN.** Hospitals and the U of A **are on
the taxable roll**; the Legislature is not. The roll publishes assessments and a
tax class, **never exemption status**.
