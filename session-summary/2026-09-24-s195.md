## 3. Technical Learnings
- **`display(Markdown(...))` in nbconvert treats paired `$` as TeX.** That swallows the text between two dollar amounts. `02_methods.py`'s `md()` escapes `$` to `\$`.
- **`verify-about.js` caps the About pod's markup at 8000 chars** (`found the pod markup to inspect`). A 3-line HTML comment pushed it to 8012, so the comment was removed rather than the cap raised. The pod is about 7.8k now, so almost any addition will trip it.
- **The CODEMAP hook fires only on the Edit/Write tools.** Python/sed edits to `web/index.html` leave it stale, so run `.venv/bin/python tools/codemap.py` by hand.
- **Playwright element screenshots time out on this box** while the map is still rendering ("waiting for element to be stable"). `page.screenshot({clip: boundingBox})` works once; the second one timed out too. Use text capture instead.
- **A verify script can pass a redesign unchanged by coincidence.** `verify-services-panel.js` §3b matched `/utility charge/` against the NEW label. Always falsify new and old checks against the previous build (serve a copy of `web/` with `git show master:web/index.html`).
- **Old METHODS.md figures reproduce from live data:**
  - 48 of 406 hoods are grey;
  - 58 points ($1.23B, 0.52%) are excluded from the lot-acre view;
  - 3,655 km of road are in the metric;

  - the citywide 2026 levy is $2.78B, and non-res is taxed 3.3× residential.
