## 3. Technical Learnings
- **A direct push to master happened.** `git checkout -b docs/brief-s249 origin/... && git merge ... 2>&1 | tail -2; make_brief && git commit && git push` failed at the checkout because the local branch already existed. The pipe reported `tail`'s status and `;` carried on, so the commit was pushed straight to master. Branch protection was bypassed, because Peter's account can bypass it.
  - Saved as memory `pipe-masks-checkout-failure`: switch branches in their own call, then assert `git branch --show-current` with `&&` before any commit.
- `qi6a-xuwt` has no `tax_class` column; use `mill_class_1`. `q7d6-ambg` names it `tax_class` and `mill_class_1`.
- `make_brief.py` prints to stdout without `--write`. That's 126 KB, so don't run it bare.
